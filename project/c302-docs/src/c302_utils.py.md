## 模块概要

`project/c302/c302_utils.py` 是 c302 的仿真结果可视化工具集。
它负责将 LEMS 仿真结果中的膜电位、活性/钙浓度和连接矩阵转换为热图、轨迹图与 PNG 文件，
并统一处理神经元/肌肉分组、自然排序、色图选择和图像保存路径。

模块的核心由两部分组成：
1. `plot_c302_results()`：从仿真结果字典中提取神经元与肌肉数据，生成膜电位和活性图
2. `generate_conn_matrix()`：从 NeuroML 文档中提取连续突触与电突触，生成四象限连接矩阵热图
