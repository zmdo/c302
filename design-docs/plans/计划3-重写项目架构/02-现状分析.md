## 问题汇总

| # | 问题 | 影响 | 严重度 |
|---|------|------|--------|
| 1 | `__init__.py` 2,195 行巨型模块，31 个函数混合 6 类职责 | 无法独立测试、维护困难 | 🔴 高 |
| 2 | 47 个 .py 文件平铺在单一目录，无子包 | 浏览困难、职责不清 | 🔴 高 |
| 3 | 无 pytest 单元测试 | 无法保证代码正确性 | 🔴 高 |
| 4 | 数据文件（XML/XLS）与 Python 源码混放 | 浏览困难、打包复杂 | 🔴 高 |
| 5 | USDR1/USDR2 代码重复率 ~90%（~225/250 行） | 维护一处忘另一处 | 🟡 中 |
| 6 | White_*.py 三文件模式完全相同 | 不必要的重复 | 🟡 中 |
| 7 | 数据读取器无 ABC，依赖鸭子类型 | 接口不清晰 | 🟡 中 |
| 8 | `analyse.py` 使用 Python 2 语法 `.has_key()` | 运行报错 | 🟡 中 |
| 9 | `parameters_C2.py` 1,956 行硬编码参数 | 数据即代码，无法外部配置 | 🟡 中 |
| 10 | C0/C1 大量复制 C 的参数代码 | 维护困难 | 🟡 中 |
| 11 | `matplotlib`/`airspeed`/`lxml` 未列入 install_requires | 安装后运行报错 | 🟡 中 |
| 12 | 配置脚本 CamelCase 命名 | 违反 PEP 8 | 🟢 低 |
| 13 | 仍用 `setup.py`，未迁移到 `pyproject.toml` | 打包方式老旧 | 🟢 低 |
| 14 | `c302_utils.py` 模块名笼统 | 实际全是可视化代码 | 🟢 低 |
| 15 | CLI 逻辑嵌入 `__init__.py` | 耦合 | 🟢 低 |
