## 分层设计

### 层间依赖规则

```
readers      ← 无内部依赖（仅依赖外部库 cect/xlrd）
parameters   ← 无内部依赖（仅依赖 YAML 数据文件）
generator    ← readers, parameters
configs      ← generator
simulation   ← configs, visualization
visualization ← 无内部依赖（仅依赖 matplotlib）
cli          ← simulation
utils        ← 无内部依赖（被所有层使用）
```

**禁止**：下层依赖上层、同层循环依赖。

### 各层职责

| 层 | 包 | 职责边界 | 原代码来源 |
|----|-----|---------|-----------|
| 数据读取 | `readers/` | 读取和解析外部数据，输出 `(cells, conns)` | 7 个读取器 + ConnectomeReader |
| 参数化 | `parameters/` | 参数定义和管理，输出 `ParameterisedModel` | bioparameters + 10 个 parameters_* |
| 生成引擎 | `generator/` | 构建 NeuroML 文档，核心业务逻辑 | `__init__.py` 的 generate() 等 |
| 配置 | `configs/` | 定义实验配置，调用生成引擎 | 16 个 c302_*.py |
| 仿真 | `simulation/` | 串联生成 → 仿真 → 绘图 | runAndPlot.py |
| 可视化 | `visualization/` | 绘图，不做数据处理 | c302_utils.py + gen_graph.py |
| 工具 | `utils/` | 路径管理、格式化等通用工具 | __init__.py 中的工具函数 |

## 关键设计决策

### 1. 数据读取层：ABC + 注册表模式

**原代码问题**：8 个读取器无统一接口，靠鸭子类型。

**方案**：定义 `BaseDataReader` ABC，所有读取器继承实现。通过注册表 + 工厂函数按名称获取读取器。

```python
class BaseDataReader(ABC):
    @staticmethod
    @abstractmethod
    def read_data(include_nonconnected_cells: bool = False) -> tuple[list[str], list[ConnectionInfo]]: ...

    @staticmethod
    @abstractmethod
    def read_muscle_data() -> tuple[dict, list[str], list[ConnectionInfo]]: ...
```

**合并策略**：
- USDR1 + USDR2 → `csv_reader.py`（参数化差异：文件名、列映射）
- White_whole + White_A + White_L4 → `white.py`（参数化差异：`WhiteDataReader` 参数）

### 2. 参数化层：YAML 数据驱动 + 继承

**原代码问题**：5,901 行硬编码 `self.add_bioparameter()` 调用。

**方案**：参数值存入 YAML 文件，Python 代码只负责加载和解析。支持 `inherits` 继承机制，C0/C1 只需声明与 C 的差异。

```yaml
# data/parameters/level_c0.yaml
level: "C0"
inherits: "level_c"
parameter_overrides:
  - name: "k_fast_max_conductance"
    value: "0 nS"
    source: "C0 disables fast K"
    certainty: "1.0"
```

### 3. 网络生成引擎：拆分为 5 个子模块

**原代码问题**：`generate()` 1,159 行，包含种群创建、连接创建、刺激注入、位置计算、文件写出。

**方案**：按职责拆为 `population.py`、`connection.py`、`stimulation.py`、`position.py`、`io.py`，由 `generate()` 主入口协调调用。

### 4. 配置脚本：注册表 + 装饰器

**原代码问题**：`runAndPlot.py` 中 200 行 elif 链硬编码配置×参数组合。

**方案**：每个配置用 `@register_config("name")` 装饰器注册到全局注册表，`run_c302()` 通过名称动态查找。

```python
@register_config("IClamp")
def setup(parameter_set: str, generate: bool = False, **kwargs):
    ...
```

### 5. 常量数据外置

**原代码问题**：`ConnectomeReader.py` 中 ~460 行硬编码 302 个神经元名称和 96 个肌肉名称。

**方案**：提取为 `data/connectome/neurons.yaml` 和 `data/connectome/muscles.yaml`，代码通过加载器读取。

### 6. 公共 API 表面

`c302/__init__.py` 仅导出用户直接使用的接口：

```python
from c302.__version__ import __version__
from c302.generator import generate
from c302.generator.stimulation import add_new_input, add_new_sinusoidal_input
from c302.simulation.runner import run_c302
from c302.cli import main
```

### 7. 不纳入重写模块的处理

以下模块因不纳入重写范围，其对应的 02 问题在新代码中自然消解：
- 问题 #8（`analyse.py` Python 2 语法）：`analyse.py` 不重写，功能由 `visualization/` 覆盖
- `CompareMain.py`、`backers.py`、`NeuroMLUtilities.py`、`c302_info.py`：不重写，不引入新代码

### 8. 等价性验证

对每个**原代码实际支持**的 `(配置, 参数集)` 组合，用原代码生成参考输出，用新代码生成对比输出，验证：
- 种群数量和实例数一致
- 连接总数和权重一致
- 刺激数量和参数一致
- BioParameter 名称-值对完全一致
- `pynml.validate_neuroml2()` 通过
