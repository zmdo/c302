## 方案一：类属性分派消除方法级重复

### 核心思路

将 `create_neuron_to_neuron_syn` / `create_neuron_to_muscle_syn` / `get_exc_syn` / `get_inh_syn` 等重复方法提升为 `_ModelBase` 的模板方法，子类仅需声明类属性。

### 类属性协议

```python
class _ModelBase(c302ModelPrototype):
    """参数工厂基类。"""

    # -- 子类必须设置的突触配置属性 --
    _exc_syn_cls: type = ExpTwoSynapse          # 兴奋性化学突触类
    _inh_syn_cls: type = ExpTwoSynapse          # 抑制性化学突触类
    _elec_syn_cls: type = GapJunction           # 电突触类
    _exc_param_fields: tuple[str, ...] = ("gbase", "erev", "decay", "rise")
    _inh_param_fields: tuple[str, ...] = ("gbase", "erev", "decay", "rise")

    # -- 参数名模板 --
    _nn_exc_template: str = "neuron_to_neuron_chem_exc_syn_%s"
    _nn_inh_template: str = "neuron_to_neuron_chem_inh_syn_%s"
    _nn_elec_template: str = "neuron_to_neuron_elec_syn_%s"
    _nm_exc_template: str = "neuron_to_muscle_chem_exc_syn_%s"
    _nm_inh_template: str = "neuron_to_muscle_chem_inh_syn_%s"
    _nm_elec_template: str = "neuron_to_muscle_elec_syn_%s"
```

### 模板方法示例

```python
def create_neuron_to_neuron_syn(self) -> None:
    """根据类属性创建神经元间突触组件。"""
    # 兴奋性
    self.neuron_to_neuron_exc_syn = self._build_syn(
        self._exc_syn_cls, self._nn_exc_template, self._exc_param_fields
    )
    # 抑制性
    self.neuron_to_neuron_inh_syn = self._build_syn(
        self._inh_syn_cls, self._nn_inh_template, self._inh_param_fields
    )
    # 电突触
    self.neuron_to_neuron_elec_syn = self._build_elec_syn(
        self._elec_syn_cls, self._nn_elec_template
    )

def _build_syn(self, syn_cls, template, param_fields):
    """根据突触类和参数字段构建突触组件。"""
    kwargs = {}
    for field in param_fields:
        bp = self.get_bioparameter(template % field)
        if bp:
            kwargs[field] = bp.value
    return syn_cls(id=template.rstrip("_%s"), **kwargs)
```

### 子类仅需声明属性

```python
class _IafActivityModel(_IafModel):
```

### 不可模板化的特例

| 类 | 方法 | 原因 | 处理 |
|---|------|------|------|
| `_IafModel` | `create_neuron_to_neuron_syn` | elec 用 `ExpTwoSynapse` 而非 `GapJunction` | 设置 `_elec_syn_cls = ExpTwoSynapse`，模板方法可覆盖 |
| `_C2Model` | `create_neuron_to_neuron_syn` | 额外创建 `DelayedGapJunction` | 保留 override，调用 `super()` 后追加 |
| `_C2Model` | `get_exc_syn` / `get_inh_syn` | 多态分派 3 种返回类型 | 保留 override |
| `_W2DModel` | `get_exc_syn` / `get_inh_syn` | 返回单例 `OutputSynapse`，无参数查找 | 保留 override |

**预估消除行数**：6 个 `create_neuron_to_neuron_syn` × ~25 行 + 6 个 `create_neuron_to_muscle_syn` × ~25 行 + 4 个 `get_exc_syn` × ~35 行 + 4 个 `get_inh_syn` × ~35 行 ≈ **580 行**。加上纯重复消除（`create_offsetcurrent_concentrationmodel`、`create_n_connection_synapse`、`is_analog_conn`）≈ **~100 行**。合计约 **680 行**。

## 方案二：修正 `_HHC0Model` 继承

```
修正前                              修正后
_ModelBase                          _ModelBase
├── _HHModel (C)                    ├── _HHModel (C)
│   ├── _HHC1Model (C1)            │   ├── _HHC0Model (C0) ← 移入
│   ├── _HHMultiCompModel (D)      │   ├── _HHC1Model (C1)
│   │   └── _HHGradedModel (D1)    │   ├── _HHMultiCompModel (D)
│   └── _C2Model (C2)              │   │   └── _HHGradedModel (D1)
├── _HHC0Model (C0) ← 脱离         │   └── _C2Model (C2)
└── _W2DModel (W2D)                 └── _W2DModel (W2D)
```

修正后 `_HHC0Model` 继承 `_HHModel`，即可复用：
- `create_models()` — 仅需 override `create_generic_*_cell` 以调用 `create_c0_cell`
- `create_offsetcurrent_concentrationmodel()` — 完全继承，删除冗余实现

## 方案三：消除纯重复对

| 重复对 | 共享位置 | 策略 |
|--------|----------|------|
| `_HHC0Model` ↔ `_HHGradedModel` (`create_n_connection_synapse`, `is_analog_conn`) | 提升至 `_HHC0Model` | `_HHGradedModel` 继承即可（当前 D1 → D → C，C0 不在链路上） |
| `_BC1Model` ↔ `_HHC1Model` (`get_exc_syn`, `get_inh_syn`) | 用类属性分派统一 | 方案一已覆盖 |

对于 C0/D1 共享 `create_n_connection_synapse`：由于 D1 不继承 C0，引入 mixin 类：

```python
class _GradedSynapse2Mixin:
    """为使用 GradedSynapse2 的模型提供 create_n_connection_synapse 和 is_analog_conn。"""
    def create_n_connection_synapse(self, prototype_syn, n, nml_doc, existing_synapses):
        ...
    def is_analog_conn(self, syn):
        return super().is_analog_conn(syn) or isinstance(syn, GradedSynapse2)
```

```python
class _HHC0Model(_GradedSynapse2Mixin, _HHModel): ...
class _HHGradedModel(_GradedSynapse2Mixin, _HHMultiCompModel): ...
```

## 方案四：xfail 粒度细化

将 xfail 从"所有测试方法 × Muscles/Oscillator 组合"缩小到仅实际失败的方法：

- **Muscles**：`test_count_exact`（TestPopulations）、`test_total_exact`（TestConnections）、`test_values_match`（TestBioParameters）— 共 3 × 9 = 27
- **Oscillator**：`test_values_match`（TestBioParameters）— 共 1 × 9 = 9
- **合计**：36 xfail（与现状一致但精准匹配，xpassed 从 162 降至 0）

```python
# 修改前：_BASELINE_MARKED = _mark_known_diffs(BASELINE_CASES)

# 修改后：拆分为三个列表
```

## 方案五：configs 自动发现

```python
def _auto_import() -> None:
    """自动导入 configs/ 目录下所有配置模块以触发注册。"""
    import importlib
    import pkgutil

    package = importlib.import_module("c302.configs")
    for importer, modname, ispkg in pkgutil.iter_modules(package.__path__):
        if not ispkg and not modname.startswith("_"):
            try:
                importlib.import_module(f"c302.configs.{modname}")
            except ImportError:
                logger.warning("无法导入配置模块: %s", modname)
```

优点：新增 `.py` 文件自动发现，零维护。
约束：模块文件名不得以 `_` 开头（`__init__.py` 已被 `pkgutil` 自动排除）。

## 文件拆分方案

### `factory/__init__.py` (~40 行)

仅包含 `create_model()` 和 `_LEVEL_TO_CLASS` 映射：

```python
"""参数工厂入口。"""
from c302.parameters.model import c302ModelPrototype

def create_model(level: str) -> c302ModelPrototype:
    # 延迟导入具体类，避免循环依赖；也使分阶段迁移时
    # 仅需存在已迁移的子模块即可运行对应层级
    from c302.parameters.factory.iaf import _IafModel, _IafActivityModel, _BC1Model
    from c302.parameters.factory.hh import _HHModel, _HHC0Model, _HHC1Model
    from c302.parameters.factory.hh_multi import _HHMultiCompModel, _HHGradedModel
    from c302.parameters.factory.special import _C2Model, _W2DModel

    _LEVEL_TO_CLASS = {
        "A": _IafModel, "B": _IafActivityModel, "BC1": _BC1Model,
        "C": _HHModel, "C0": _HHC0Model, "C1": _HHC1Model,
        "C2": _C2Model, "D": _HHMultiCompModel, "D1": _HHGradedModel,
        "W2D": _W2DModel,
    }
    ...
```

### `factory/base.py` (~200 行)

- `_ModelBase` 类定义
- 类属性协议声明
- 模板方法：`create_neuron_to_neuron_syn`、`create_neuron_to_muscle_syn`、`_build_syn`、`_build_elec_syn`
- 通用方法：`get_exc_syn`、`get_inh_syn`、`get_elec_syn`、`_get_elec_syn_params`
- `_GradedSynapse2Mixin`

### `factory/iaf.py` (~150 行)

- `_IafModel`（A）：override `create_generic_*_cell`、`create_offset`
- `_IafActivityModel`（B）：override `create_generic_*_cell`，设置类属性
- `_BC1Model`（BC1）：设置类属性

### `factory/hh.py` (~200 行)

- `_HHModel`（C）：override `create_models`、`create_generic_*_cell`、`create_offsetcurrent_concentrationmodel`
- `_HHC0Model`（C0）：继承 `_GradedSynapse2Mixin, _HHModel`，override `create_generic_*_cell`（用 `create_c0_cell`），设置类属性
- `_HHC1Model`（C1）：设置类属性

### `factory/hh_multi.py` (~150 行)

- `_HHMultiCompModel`（D）：override `create_models`、`create_neuron_cell`
- `_HHGradedModel`（D1）：继承 `_GradedSynapse2Mixin, _HHMultiCompModel`，设置类属性

### `factory/special.py` (~400 行)

- `_C2Model`（C2）：保留全部 12 个方法（复杂度高，难以模板化）
- `_W2DModel`（W2D）：保留 override 方法
