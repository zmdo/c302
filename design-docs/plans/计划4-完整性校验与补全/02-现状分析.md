## 未实现层级的技术复杂度

### BC1（中等复杂度 — ~230 行原始代码）

- 细胞模型：IafActivityCell（复用 B 级实现）
- 突触模型：GradedSynapse（标准 NeuroML，类似 C1）
- 技术要点：混合体——B 级细胞 + C1 级突触
- 可复用：`_IafActivityModel` 的细胞创建 + `_HHC1Model` 的突触创建

### W2D（中等复杂度 — ~230 行原始代码）

- 细胞模型：CellW2D（自定义，仅 id 参数，bias/gain 在 XML 定义）
- 突触模型：OutputSynapse（连续传输突触）
- 技术要点：2 个新自定义组件类型，但参数极少
- 特殊行为：`create_muscle_to_muscle_syn()` 方法

### C2（极高复杂度 — ~1956 行原始代码）

- 细胞模型：HH 单室（继承 C 级，但肌肉生物物理参数独立）
- 突触模型：**9 种自定义组件类型**
  1. `SwitchedGapJunction` — 开关控制间隙连接
  2. `DelayedGapJunction` — sigmoid 时间调制间隙连接
  3. `ProprioGapJunction` — 本体感受调制间隙连接
  4. `ProprioGapJunction2` — 增强版（含时间/电压门控）
  5. `DelayedGradedSynapse` — 延迟模拟突触
  6. `NeuronMuscle` — 肌肉本体感受反馈突触
  7. `MuscleConcentrationModel` — 简化肌肉钙模型
  8. `MuscleConcentrationModel2` — 扩展版（含 sigmoid 阈值）
  9. `GradedSynapse2` — 双组分模拟突触（已在 factory 中实现）
- 特殊方法：`create_muscle_to_muscle_syn()`、`is_elec_conn()` 覆盖、`is_analog_conn()` 覆盖、per-connection 参数覆盖
- 技术要点：本质上是一个独立的子项目

### D/D1（已实现但集成未验证）

- Factory 类已实现（`_HHMultiCompModel` / `_HHGradedModel`）
- Generator `population.py` 有 D 级分支（`is_level_D()` → `create_neuron_cell()`）
- 潜在问题：morphology 文件路径解析、`cells/` 输出目录创建、per-neuron `.cell.nml` 文件写出
- 304 个 morphology 文件已存在于 `data/morphology/`

## factory.py 结构问题

当前 `factory.py` 为 **1419 行单体文件**，包含：
- 2 个自定义组件类（IafActivityCell、GradedSynapse2）— ~70 行
- 2 个细胞构建函数（_create_hh_cell、_create_c0_cell）— ~200 行
- 8 个模型类（_ModelBase + 7 个子类）— ~1100 行
- 1 个入口函数（create_model）— ~20 行

新增 BC1/C2/W2D 将进一步膨胀（C2 单独需要 ~800 行），若不拆分将超过 2200 行。
