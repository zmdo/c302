# 01 - 概述与目标

## 背景

计划 3 完成了 c302 的架构重写（`project_r1/`），实现了 7 个参数层级（A/B/C/C0/C1/D/D1）和 16 个配置脚本的功能等价。但等价性验证存在严重不足：

1. **覆盖率低**：原始 test.sh 测试 65 种 (配置, 参数集) 组合、`runAndPlot.py -all` 测试 72 种，当前 `test_equivalence.py` 仅覆盖 **10 种**（14%）
2. **断言质量弱**：14 个测试方法中仅 3 个做精确数值比对，其余均为 `> 0` 存在性检查；`test_has_stimuli` 断言 `>= 0` 恒真
3. **D/D1 完全未测**：factory 已实现但等价性测试将其排除（注释："暂时排除，直到 generator 对 D 族的 per-neuron cell 创建完全对接"）
4. **3 个参数层级未实现**：BC1、C2、W2D 仅有 YAML 数据但无 factory 类，无法生成网络
5. **无精确比对**：未对新旧代码做逐连接、逐参数、逐种群的数值级 diff

## 目标

1. **补全 factory**：为 BC1、C2、W2D 三个参数层级实现 factory 类，使全部 10 个层级可用
2. **修通 D/D1 生成链路**：排查并修复 D/D1 层级在 generator 中的 per-neuron cell 创建问题
3. **扩展等价性测试矩阵**：覆盖原始 `-all` 矩阵的全部 72 种组合（9 层级 × 8 核心配置）
4. **升级断言为精确比对**：种群数量精确相等、连接数量精确相等、BioParameter 值逐一相等
5. **建立参考基线**：用原始代码生成所有 72 种组合的 NeuroML 输出，提取种群/连接/参数计数，固化为测试基准数据
6. **修复已知断言缺陷**：`test_has_stimuli` 的 `>= 0` 恒真断言改为 `> 0`

## 不做什么

1. **不做仿真级验证**：不运行 jNeuroML/NEURON 仿真来比较时序波形，仅验证网络生成阶段的结构等价性
2. **不修改 YAML 数据文件**：参数值不变，仅新增 factory 类来消费已有 YAML
3. **不新增配置脚本**：16 个配置已全部实现且与原代码 1:1 对应
4. **不追加特殊配置的等价性测试**：7 个特殊配置（RIA/TapWithdrawal/MuscleTest/MusclesSine/OscillatorM/IClampMuscle/TargetMuscle）不在原始 test.sh 核心矩阵中，暂不纳入精确比对范围（但会做生成成功性测试）
5. **不修改原始代码**：`c302/` 目录下的原始代码仅用于生成基线数据，不做任何修改
