## 方案一：分阶段实施（推荐）

### 阶段划分

| 阶段 | 内容 | 前置 | 产出 |
|------|------|------|------|
| 一 | 生成参考基线 | 无 | `baselines/*.json` 72 组 |
| 二 | factory.py 拆分 | 无 | custom_types.py + cell_builder.py |
| 三 | D/D1 集成修通 | 阶段二 | D/D1 × 7 配置 = 14 组等价 |
| 四 | 实现 BC1 factory | 阶段二 | BC1 × 7 配置 = 7 组等价 |
| 五 | 实现 W2D factory | 阶段二 | W2D × 8 配置 = 8 组等价 |
| 六 | 实现 C2 factory | 阶段二 | C2 × 8 配置 = 8 组等价 |
| 七 | 等价性测试升级 | 阶段一~六 | 72 组精确断言 |
| 八 | 收尾 | 阶段七 | 代码风格/覆盖率/提交 |

### 为什么不先全部实现再统一测试？

C2 极度复杂（1956 行、9 个自定义类型），如果放到最后才发现架构问题，回溯成本极高。分阶段实施允许：
- 阶段三验证 D/D1 集成的正确性（可能暴露 generator 路径问题）
- 阶段四~五处理中等复杂度层级（BC1/W2D），积累自定义类型处理经验
- 阶段六用已验证的模式处理 C2

```
    覆盖: get_inh_syn → GradedSynapse
```

#### `_W2DModel`（W2D）

```
_W2DModel(_ModelBase)
    新增: create_generic_muscle_cell → CellW2D
    新增: create_generic_neuron_cell → CellW2D

    新增: create_neuron_to_muscle_syn → OutputSynapse + GapJunction
    新增: create_muscle_to_muscle_syn → OutputSynapse
```


## Generator 适配

### D/D1 路径修复

当前 `population.py` 的 D 级分支流程：

```
is_level_D() 为真
  → component = cell（而非 generic_neuron_cell.id）
  → load morphology from data/morphology/{cell}.cell.nml
  → params.create_neuron_cell(cell, morphology)
  → write cells/{cell}_D.cell.nml
```

潜在问题点：
1. `cells/` 子目录未自动创建 → 需确保 `os.makedirs(cells_dir, exist_ok=True)`
2. Morphology 文件名匹配 → 某些细胞名可能不在 `data/morphology/` 中
3. include 文件路径 → `nml_doc.includes` 中添加的路径需指向正确位置

### W2D 特殊处理

W2D 使用 `CellW2D`（非标准 NeuroML），generator 的 `is_cond_based_cell()` 和 `is_level_D()` 均不覆盖它。需要：
- `is_level_X()` 方法覆盖 W2D（W2D 在原始代码中走 `is_level_X()` 分支 → 原始代码通过 `generic_neuron_cell` 和 `generic_muscle_cell` 属性存在来判断，W2D 同时有两者）
- Generator 的细胞注册分支需支持 W2D 的 CellW2D 类型

### C2 特殊处理

C2 有两个特殊 generator 需求：
1. `create_muscle_to_muscle_syn()` — 需在 generator 连接循环中增加肌肉间连接路径
2. `create_offsetcurrent_concentrationmodel()` — 分别创建神经元和肌肉浓度模型
3. `is_elec_conn()` / `is_analog_conn()` 覆盖 — generator 连接类型分发需调用这些方法

### 断言升级

| 指标 | 旧断言 | 新断言 |
|------|--------|--------|
| 种群数量 | `>= len(cells)` | `== baseline["populations"]["count"]` |
| 连接数量 | `> 0` | `== baseline["connections"]["total"]` |
| 刺激数量 | `>= 0`（恒真） | `== baseline["stimuli"]["count"]` |
| BioParameter 数量 | `> 0` | `== baseline["bioparameters"]["count"]` |
| 细胞模型计数 | 部分精确 | `== baseline["cell_models"]["iaf_cells"]` 等 |
| 突触模型计数 | 部分存在性 | `== baseline["synapse_models"]["exp_two_synapses"]` 等 |

### 参考基线加载

```python
import json
from pathlib import Path

BASELINES_DIR = Path(__file__).parent / "fixtures" / "baselines"

def load_baseline(config: str, level: str) -> dict:
    path = BASELINES_DIR / f"{config}_{level}.json"
    return json.loads(path.read_text())
```
