## 验证流程

### 每文件验证

```bash
# 1. 从 git HEAD 提取原始版本
git show HEAD:project/c302/{文件名} > /tmp/orig_{文件名}

# 2. 验证代码等价性
python scripts/verify-comment-only/verify_comment_only.py /tmp/orig_{文件名} project/c302/{文件名}
```

### 每阶段验证

阶段完成后，对该阶段全部文件进行批量验证：

```bash
# 提取该阶段所有文件的原始版本到临时目录
mkdir -p /tmp/originals_phase_N
for f in <该阶段文件列表>; do
    git show HEAD:project/c302/$f > /tmp/originals_phase_N/$f
done

# 批量验证
python scripts/verify-comment-only/verify_comment_only.py /tmp/originals_phase_N/ project/c302/
```
