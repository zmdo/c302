## 验证流程

> **执行顺序**：注释修改完成后，必须先更新代码头部索引，再执行代码等价验证。

### 步骤一：更新代码头部注释块（类与方法索引）

注释修改有两种情况会导致头部索引失效，每次修改文件后必须重新运行 `gen_index.py`：

1. **行号偏移**：插入/删除注释行导致函数定义行号变化
2. **描述文本过时**：翻译/修改 docstring 首行（A 类修正）后，头部索引中的 `— 描述` 字段需同步更新

> `gen_index.py` 会读取每个函数/类的 **docstring 首行**作为描述文本写入头部索引。
> 因此 A 类修正（翻译 docstring）后，**必须**运行 `gen_index.py --write`，
> 否则头部索引仍保留旧的英文描述，需要额外手动修补。

```bash
SKILL_SCRIPTS=".github/skills/python-annotation-engineering/scripts"

# 运行两遍确保行号收敛（索引本身也占行）
python $SKILL_SCRIPTS/gen_index.py project/c302/{文件名} --write
python $SKILL_SCRIPTS/gen_index.py project/c302/{文件名} --write

# 验证索引与实际定义一致
python $SKILL_SCRIPTS/check_index.py project/c302/{文件名}
# 期望输出：✅ 所有文件的「类与方法索引」与实际代码一致。
```

### 步骤二：代码等价验证

> **注意**：不要用 PowerShell `Out-File` 导出 git 内容，会引入 UTF-16 BOM 导致哈希不匹配。
> 必须用 Python `subprocess` 以二进制方式提取原始文件。

```bash
# 用 Python 从 git HEAD 提取原始版本（避免 BOM 问题）
python -c "
import subprocess, os, tempfile
f = 'project/c302/{文件名}'
data = subprocess.check_output(['git', 'show', f'HEAD:{f}'])
tmp = os.path.join(tempfile.gettempdir(), 'orig_{文件名}')
open(tmp, 'wb').write(data)
"

# 验证代码等价性（仅注释变更）
python $SKILL_SCRIPTS/verify_comment_only.py \
    $(python -c "import tempfile,os; print(os.path.join(tempfile.gettempdir(),'orig_{文件名}'))") \
    project/c302/{文件名}
# 期望输出：[OK]   {文件名} — 代码等价，仅注释变更
```

### 每阶段批量验证

阶段完成后，对该阶段全部文件一次性批量验证：

```python
import subprocess, os, tempfile

SKILL_SCRIPTS = ".github/skills/python-annotation-engineering/scripts"
tmp_dir = tempfile.gettempdir()

files = [
    # 填入该阶段文件列表，如：
    # "ConnectomeReader.py",
]

# 步骤一：批量更新索引
for f in files:
    path = f"project/c302/{f}"
    subprocess.run(["python", f"{SKILL_SCRIPTS}/gen_index.py", path, "--write"])
    subprocess.run(["python", f"{SKILL_SCRIPTS}/gen_index.py", path, "--write"])
    subprocess.run(["python", f"{SKILL_SCRIPTS}/check_index.py", path])

# 步骤二：批量等价验证
for f in files:
    path = f"project/c302/{f}"
    orig = os.path.join(tmp_dir, f"orig_{f}")
    data = subprocess.check_output(["git", "show", f"HEAD:{path}"])
    open(orig, "wb").write(data)
    subprocess.run(["python", f"{SKILL_SCRIPTS}/verify_comment_only.py", orig, path])
```
