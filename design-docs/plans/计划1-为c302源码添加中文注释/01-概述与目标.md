# 01 - 概述与目标

## 背景

c302 是 OpenWorm 项目的核心建模框架，代码库共 57 个 Python 源文件、12,749 行代码。现有代码中：

- 大部分函数缺少行内注释，逻辑意图难以从代码直接理解
- 少量已有注释为英文，与项目中文化方向不一致
- 缺乏统一的领域词汇表，生物学/NeuroML 术语无统一中文对照

这给后续维护、二次开发以及新贡献者上手带来了较高门槛。

## 目标

1. 为 c302 核心 Python 源文件添加中文行内注释，覆盖所有关键逻辑块（条件分支、循环、异常处理、复杂表达式）
2. 将现有英文注释翻译为中文注释（原位替换）
3. 建立统一的领域词汇表（中英文对照），存放于 `design-docs/glossary.md`
4. 编写代码等价性验证脚本，确保注释操作不改变任何可执行代码
5. 按照分析报告所揭示的模块重要性，制定注释顺序（优先注释核心层，再覆盖外围模块）

## 不做什么

- 不修改任何可执行代码（逻辑、变量名、函数签名、导入、字符串字面量均不变）
- 不添加文件头注释块（文件头格式化属于独立的代码风格规范任务）
- 不添加 docstring（docstring 格式化属于独立的代码风格规范任务）
- 不修改 XML / LEMS / NeuroML 文件
- 不对 `data/` 目录中的数据文件进行任何修改
- 不对测试文件进行注释（本次范围仅限生产代码）
