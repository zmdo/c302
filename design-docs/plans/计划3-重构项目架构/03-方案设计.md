## 向后兼容策略

### 原则

所有旧导入路径在重构后**至少一个版本周期内**继续可用，通过兼容层实现。

### 兼容层设计

**顶层 `c302/__init__.py`**：

## BaseDataReader ABC 设计

```python
# c302/readers/__init__.py

from abc import ABC, abstractmethod

class BaseDataReader(ABC):
    """连接组数据读取器的抽象基类。

    所有读取器必须实现 ``read_data()`` 和 ``read_muscle_data()`` 两个静态方法。
    """

    @staticmethod
    @abstractmethod
    def read_data(include_nonconnected_cells=False):
        """读取连接组数据。

        :param include_nonconnected_cells: 是否包含无连接的细胞
        :return: ``(cells: list[str], conns: list[ConnectionInfo])``
        """
        ...

    @staticmethod
    @abstractmethod
    def read_muscle_data():
        """读取神经元-肌肉连接数据。

        :return: ``(neurons2muscles: dict, muscles: list[str], muscle_conns: list[ConnectionInfo])``
        """
        ...

# 读取器注册表
READER_REGISTRY = {}

def register_reader(name):
    """装饰器：将读取器注册到全局注册表。"""
    def decorator(cls):
        READER_REGISTRY[name] = cls
        return cls
    return decorator

def list_readers():
    """列出所有已注册的读取器名称。"""
    return list(READER_REGISTRY.keys())
```
