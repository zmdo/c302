### 4. 动态加载路径兼容

`load_data_reader()` 和配置脚本中的 `importlib.import_module()` 调用使用旧路径名，兼容模块确保旧路径可解析。同时在 `data_bridge.py` 中添加路径映射：

```python
# c302/core/data_bridge.py

_READER_PATH_MAP = {
    "SpreadsheetDataReader": "c302.readers.spreadsheet",
    "UpdatedSpreadsheetDataReader": "c302.readers.csv_reader",
    "UpdatedSpreadsheetDataReader2": "c302.readers.csv_reader",
    "OpenWormReader": "c302.readers.openworm",
    "White_whole": "c302.readers.white",
    "White_A": "c302.readers.white",
    "White_L4": "c302.readers.white",
}

def load_data_reader(data_reader):
    """动态加载数据读取器模块。"""
    # 优先尝试新路径
    new_path = _READER_PATH_MAP.get(data_reader)
    if new_path:
        return importlib.import_module(new_path)
    # 回退到旧路径（兼容自定义读取器）
    return importlib.import_module("c302.%s" % data_reader)
```

### 5. XML 资源路径更新

代码中引用 XML 文件的位置需要更新路径。使用 `importlib.resources` 或相对路径：

```python
# c302/core/io.py

import os
_C302_DIR = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))

def get_resource_path(filename):
    """获取 resources/ 子目录中文件的绝对路径。"""
    return os.path.join(_C302_DIR, "resources", filename)
```
