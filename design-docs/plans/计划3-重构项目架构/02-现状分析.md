### 动态加载约定

| 加载方式 | 模式 | 调用者 |
|----------|------|--------|
| 参数集加载 | `importlib.import_module("c302.parameters_%s" % level)` | 配置脚本 |
| 读取器加载 | `importlib.import_module("c302.%s" % reader)` | `__init__.py::load_data_reader()` |
| 配置加载 | `importlib.import_module("c302.c302_%s" % config)` | `runAndPlot.py` |

## 问题汇总

| 问题 | 影响 | 严重度 |
|------|------|--------|
| 47 个文件平铺单一目录，无法体现四层架构 | 新开发者上手成本高，模块边界模糊 | 🔴 高 |
| `__init__.py` 2195 行承担 6 类职责 | 无法独立测试、修改冲突概率高 | 🔴 高 |
| 无 pytest 单元测试框架 | 无法快速定位回归、无覆盖率统计 | 🔴 高 |
| USDR1/USDR2 ~90% 代码重复 | Bug 修复需双份同步 | 🟡 中 |
| White 适配器三文件模式相同 | 认知负担 | 🟡 中 |
| 数据读取器无 ABC | 新增读取器无编译期检查 | 🟡 中 |
| `analyse.py` Python 2 语法 | Python 3 下运行时崩溃 | 🟡 中 |
| `matplotlib`/`airspeed`/`lxml` 未声明 | `pip install` 后运行时缺依赖 | 🟡 中 |
| XML/XLS 文件与 .py 混放 | 目录杂乱 | 🟢 低 |
| `NeuroMLUtilities.py` 死导入 | 不必要的依赖耦合 | 🟢 低 |
| 配置脚本 CamelCase 命名 | PEP 8 不一致 | 🟢 低 |
| `setup.py` 未迁移 pyproject.toml | 打包方式老旧 | 🟢 低 |
