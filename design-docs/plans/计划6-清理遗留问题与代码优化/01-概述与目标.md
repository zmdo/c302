# 01 - 概述与目标

## 背景

计划 5 完成后，`factory.py`（1,877 行）已拆分为 `factory/` 子包（6 文件、1,489 行），整体评级从 B+ 提升至 A−。代码复审报告（`comment-20260419-8b0c1a8`）在"遗留问题与建议"章节指出 4 项待改进：

1. 参数名 `type` 遮蔽 Python 内置 `type()`，散布于 12 处方法签名
2. `configs/__init__.py` 的 `_auto_import()` 无幂等保护且静默吞没 `ImportError`
3. `factory/special.py`（636 行）仍可进一步拆分——`_C2Model`（492 行）和 `_W2DModel`（70 行）无继承关系
4. `factory/__init__.py` 中 `_LEVEL_TO_CLASS` 字典在 `create_model()` 每次调用时重建
5. `custom_types.py` 存在 5 个重复类定义（已在复审时清理）

## 目标

1. **全局重命名 `type` → `conn_type`**：消除 12 处对 Python 内置 `type()` 的遮蔽
2. **优化 `_auto_import()`**：添加幂等哨兵标志 + 将 `except ImportError: pass` 改为 `logging.debug()` 记录
3. **拆分 `special.py`**：将 `_C2Model` 和 `_W2DModel` 各自独立为文件
4. **提升 `_LEVEL_TO_CLASS` 为模块级常量**：避免每次调用 `create_model()` 重建
5. **确保所有修改通过全量回归测试**：1472 passed, 36 xfailed, 0 FAILED

## 不做什么

- 不修改 `generator/connection.py` 中的 `conn_type` 变量名（它已经是 `conn_type`，不受影响）
- 不增加新功能或新测试用例（仅适配既有测试）
- 不修改 `readers/` 中 `register_reader` 的 `type` 类型注解（那是 Python 内置 `type` 的合法使用）
- 不重构 `_C2Model` 的内部方法（仅搬迁文件，不改逻辑）
