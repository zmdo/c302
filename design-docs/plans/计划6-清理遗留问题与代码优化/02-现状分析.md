## 问题 2：`_auto_import()` 实现缺陷

```python
# configs/__init__.py L67-80
def _auto_import() -> None:
    import importlib
    import pkgutil
    for finder, name, ispkg in pkgutil.iter_modules(__path__, __name__ + "."):
        try:
            importlib.import_module(name)
        except ImportError:
            pass  # ← 静默吞没真实导入错误
```

- **无幂等保护**：每次 `get_config()` 调用都执行 `_auto_import()`，重复扫描文件系统
- **静默吞没错误**：`except ImportError: pass` 可能隐藏配置模块中的真实导入错误（如缺少依赖）

## 问题 3：`special.py` 体量过大

`special.py` 636 行包含两个完全独立的类：

| 类 | 行数 | 方法数 | 说明 |
|----|------|--------|------|
| `_C2Model` | 492 | 12 | C2 层级，最复杂的自定义组件模型 |
| `_W2DModel` | 70 | 9 | W2D 层级，简单偏置-增益模型 |

两者无继承关系，无共享方法，可独立存在。

## 问题 4：`_LEVEL_TO_CLASS` 重复构建

```python
# factory/__init__.py L54-65
def create_model(level: str) -> c302ModelPrototype:
    _LEVEL_TO_CLASS: dict[str, type] = {  # ← 每次调用重建
        "A": _IafModel,
        ...
    }
```

虽然性能影响极小，但不符合常量语义。

## 问题汇总

| 问题 | 影响 | 严重程度 |
|------|------|---------|
| `type` 遮蔽内置函数 | IDE 警告、代码可读性降低 | 🟡中 |
| `_auto_import()` 无幂等保护 | 微小性能损失、错误可能被隐藏 | 🟢低 |
| `special.py` 体量过大 | 单文件 636 行，不利于维护 | 🟡中 |
| `_LEVEL_TO_CLASS` 函数内重建 | 不符合常量语义 | 🟢低 |
