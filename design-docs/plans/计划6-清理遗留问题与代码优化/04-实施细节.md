## 阶段 3：优化 `_auto_import()`

### 3.1 修改 `configs/__init__.py`

在模块顶部添加 logger：

```python
import logging

logger = logging.getLogger(__name__)
```

修改 `_auto_import()` 函数：

```python
_imported = False

def _auto_import() -> None:
    global _imported
    if _imported:
        return
    _imported = True

    import importlib
    import pkgutil

    for finder, name, ispkg in pkgutil.iter_modules(__path__, __name__ + "."):
        try:
            importlib.import_module(name)
        except ImportError:
            logger.debug("配置模块 %s 导入失败", name, exc_info=True)
```
