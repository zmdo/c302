# 03 - 工厂方法重复

## 问题概述

`factory/` 子包中存在结构性的代码重复：多个方法在逻辑上只是参数不同，但当前以独立方法的形式分别实现。

---

## 问题 #1：`get_exc_syn` 与 `get_inh_syn` 结构重复（base.py）

### 位置

- `factory/base.py` L201–L241（`get_exc_syn`）
- `factory/base.py` L244–L282（`get_inh_syn`）

### 现状分析

两个方法的代码结构完全平行：

| 步骤 | `get_exc_syn` | `get_inh_syn` |
|------|-------------|-------------|
| conn_type 分发 | 相同 3-branch if/elif/else | 相同 3-branch if/elif/else |
| 模板字符串 | `"..._exc_syn_%s"` | `"..._inh_syn_%s"` |
| 参数字段映射 | `_exc_param_fields` | `_inh_param_fields` |
| 字段→构造参数映射 | `_exc_param_to_kwarg` | `_inh_param_to_kwarg` |
| 突触类属性 | `_exc_syn_cls` | `_inh_syn_cls` |
| 调用 `_build_syn_from_params` | ✓ | ✓ |

差异仅在于 5 个属性名中的 `"exc"` 与 `"inh"` 后缀。

### 代码示例（当前）

```python
def get_exc_syn(self, pre_cell, post_cell, conn_type):
    specific = "%s_to_%s_exc_syn_%%s" % (pre_cell, post_cell)
    if conn_type == "neuron_to_neuron":
        default = "neuron_to_neuron_exc_syn_%s"
    elif conn_type == "neuron_to_muscle":
        default = "neuron_to_muscle_exc_syn_%s"
    else:
        default = "neuron_to_neuron_exc_syn_%s"
    return self._build_syn_from_params(
        pre_cell, post_cell, specific, default,
        self._exc_param_fields, self._exc_param_to_kwarg, self._exc_syn_cls,
    )

def get_inh_syn(self, pre_cell, post_cell, conn_type):
    specific = "%s_to_%s_inh_syn_%%s" % (pre_cell, post_cell)
    if conn_type == "neuron_to_neuron":
        default = "neuron_to_neuron_inh_syn_%s"
    elif conn_type == "neuron_to_muscle":
        default = "neuron_to_muscle_inh_syn_%s"
    else:
        default = "neuron_to_neuron_inh_syn_%s"
    return self._build_syn_from_params(
        pre_cell, post_cell, specific, default,
        self._inh_param_fields, self._inh_param_to_kwarg, self._inh_syn_cls,
    )
```

### 建议方案

合并为通用私有方法 `_get_chem_syn`：

```python
def _get_chem_syn(self, pre_cell, post_cell, conn_type, polarity):
    """通用化学突触构建方法。"""
    specific = f"{pre_cell}_to_{post_cell}_{polarity}_syn_%s"
    default = f"{conn_type}_{polarity}_syn_%s"
    fields = getattr(self, f"_{polarity}_param_fields")
    mapping = getattr(self, f"_{polarity}_param_to_kwarg")
    cls = getattr(self, f"_{polarity}_syn_cls")
    return self._build_syn_from_params(
        pre_cell, post_cell, specific, default, fields, mapping, cls,
    )

def get_exc_syn(self, pre_cell, post_cell, conn_type):
    return self._get_chem_syn(pre_cell, post_cell, conn_type, "exc")

def get_inh_syn(self, pre_cell, post_cell, conn_type):
    return self._get_chem_syn(pre_cell, post_cell, conn_type, "inh")
```

减少行数：~80→~20（−75%）。

## 问题 #2：C2 `get_elec_syn` 逐字段查询（c2.py）

### 位置

- `factory/c2.py` L292–L370

### 现状分析

`get_elec_syn` 中连续调用 9 次 `self.get_conn_param`，每次仅字段名不同：

```python
gbase  = self.get_conn_param(pre, post, "%s_to_%s_elec_syn_%s",
             "neuron_to_neuron_elec_syn_%s", "gbase")
sigma  = self.get_conn_param(pre, post, "%s_to_%s_elec_syn_%s",
             "neuron_to_neuron_elec_syn_%s", "sigma")
mu     = self.get_conn_param(pre, post, "%s_to_%s_elec_syn_%s",
             "neuron_to_neuron_elec_syn_%s", "mu")
p_gbase = self.get_conn_param(pre, post, "%s_to_%s_elec_syn_%s",
             "neuron_to_neuron_elec_syn_%s", "p_gbase")
# ... 继续 5 次
```

四个参数 `(pre, post, specific_template, default_template)` 完全相同，仅末尾的 `field` 不同。

### 建议方案

引入批量查询辅助方法：

```python
def _get_conn_params_batch(self, pre, post, specific, default, fields):
    """批量查询多个连接参数字段。"""
    return {f: self.get_conn_param(pre, post, specific, default, f)
            for f in fields}
```

调用简化为：

```python
elec_fields = ("gbase", "sigma", "mu", "p_gbase", "p_ar", "p_ad",
               "beta", "vth", "erev")
vals = self._get_conn_params_batch(pre, post, spec, default, elec_fields)
syn = GapJunctionSynapseC2(id=syn_id, **vals)
```

减少行数：~50→~10（−80%）。

## 问题 #3：C2 `get_exc_syn` 多分支重复（c2.py）

### 位置

- `factory/c2.py` L375–L500

### 现状分析

`get_exc_syn` 按 `conn_type` 分为三个分支，每个分支独立调用 `get_conn_param`：

| 分支 | 字段数 | 行数 |
|------|------:|-----:|
| `neuron_to_neuron` | 8 | 16 |
| `neuron_to_muscle` | 5 | 10 |
| `muscle_to_neuron` | 6 | 12 |

分支间的差异在于字段列表和构造器类不同，但查询模式完全一致。

### 建议方案

定义每种 `conn_type` 的字段映射和构造器：

```python
_C2_EXC_SYN_CONFIG = {
    ConnType.NEURON_TO_NEURON: {
        "fields": ("conductance", "erev", "delta", "vth", "k", "ar", "ad", "beta"),
        "cls": GradedSynapseC2,
    },
    ConnType.NEURON_TO_MUSCLE: {
        "fields": ("conductance", "erev", "delta", "vth", "k"),
        "cls": GradedSynapseC2NMJ,
    },
    ConnType.MUSCLE_TO_NEURON: {
        "fields": ("conductance", "erev", "ar", "ad", "beta", "cath"),
        "cls": GradedSynapseC2MN,
    },
}
```

然后统一调用 `_get_conn_params_batch` + 构造。

## 问题 #4：`conn_type → default` 映射冗余（base.py + c2.py）

### 位置

- `factory/base.py` L212–L218, L255–L261, L309–L325
- `factory/c2.py` L297–L310

### 现状分析

当前使用 3-branch `if/elif/else` 构建 `default` 模板：

```python
if conn_type == "neuron_to_neuron":
    default = "neuron_to_neuron_exc_syn_%s"
elif conn_type == "neuron_to_muscle":
    default = "neuron_to_muscle_exc_syn_%s"
else:
    default = "neuron_to_neuron_exc_syn_%s"
```

但 `default` 字符串的前缀本身就是 `conn_type` 的值。

### 建议方案

```python
# 直接推导（1 行替代 6 行）
default = f"{conn_type}_exc_syn_%s"
```

对于 `else` 分支需回退到 `neuron_to_neuron` 的情况，可保留一行兜底：

```python
prefix = conn_type if conn_type in (ConnType.N2N, ConnType.N2M, ConnType.M2M) \
         else ConnType.N2N
default = f"{prefix}_exc_syn_%s"
```
