# 01 - 总览与结论

## 重构背景

计划 5（消除参数层重复与测试加固）是 c302 重构的第五阶段。前一轮评估（comment-20260419-4f99cb7）指出 `parameters/factory.py`（1,877 行、11 个类、72 个方法）是重构后最大的技术债——方法级重复率达 58%，是事实上的新 God Object。

计划 5 的目标：
1. 将 `factory.py` 拆分为 `factory/` 子包（按模型族分文件）
2. 提取共享方法为基类方法或 mixin，消除方法级重复
3. 整理 xfail 标记，消除误标的 xpassed
4. 新增 configs 自动发现与 factory 单元测试

## 关键结论

1. **God Object 已消除**：`factory.py`（1,877 行）拆分为 6 个文件，最大 636 行（`special.py`），符合单一职责原则。
2. **xpassed 全部清零**：从 162 个 xpassed 降至 0，说明 xfail 标记精确对应真正未通过的测试。
3. **测试加固有效**：新增 187 个测试用例（configs 自动发现 + factory 单元测试），总量达 1,472。
4. **继承体系优化**：修复了 `_HHC0Model` 错误继承 `_HHModel` 的问题，改为继承 `_GradedSynapse2Mixin + _ModelBase`。
5. **代码复审发现 2 个潜在 bug**：`_C2Model.get_exc_syn` 变量未初始化 + `test_graded_synapse2_count` 空断言，均已修复。
