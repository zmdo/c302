# 03 - 架构评估

## factory/ 子包结构

```
parameters/factory/
├── __init__.py     ← create_model(level) 公共入口
├── base.py         ← 基类 + mixin
├── iaf.py          ← IAF 族
├── hh.py           ← HH 单腔室族
├── hh_multi.py     ← HH 多腔室族
└── special.py      ← 独立模型
```

**关键修正**：`_HHC0Model` 原错误继承自 `_HHModel`（C0 使用 GradedSynapse2 而非 HH 标准突触），现改为 `_GradedSynapse2Mixin + _ModelBase`。

## 设计改进

### 1. _GradedSynapse2Mixin 提取

Level C0 和 D1 共享 GradedSynapse2 突触注册逻辑，提取为 `_GradedSynapse2Mixin`（`base.py` L352-387），包含：
- `create_n_connection_synapse()` — 识别 GradedSynapse2 并追加到 `nml_doc.graded_synapses`
- `is_analog_conn()` — 扩展模拟连接判断

### 2. 共享突触方法上提

`create_neuron_to_neuron_syn()`、`create_neuron_to_muscle_syn()` 等高频重复方法上提到 `_ModelBase`，子类仅需提供参数名称差异。

### 3. configs 自动发现

`configs/__init__.py` 新增 `_auto_import()` 机制，自动扫描目录下所有 `.py` 模块并触发 `@register_config` 装饰器注册，新增配置文件零额外配置。

## 依赖方向（更新）

```
configs/ ──→ generator/ ──→ readers/
  ↓              ↓
parameters/   utils/
  ├── model.py
  ├── bio.py
  ├── loader.py
  ├── cell_builder.py
  ├── custom_types.py
  └── factory/           ← 新子包
      ├── __init__.py
```
