# 01 - 总览与结论

## 重构背景

计划 6（清理遗留问题与代码优化）是 c302 重构的第六阶段。计划 5 完成后的遗留问题包括：

1. `special.py`（636 行）包含两个不相关的模型类 `_C2Model` 和 `_W2DModel`，违反单一职责
2. `get_syn` 系列方法的参数 `type` 遮蔽了 Python 内建函数
3. `_auto_import()` 缺少幂等保护，每次调用都重新扫描
4. `_LEVEL_TO_CLASS` 字典在 `create_model()` 函数体内部，每次调用都重新创建

## 关键结论

1. **`special.py` 已拆分**：`_C2Model`（545 行）→ `c2.py`，`_W2DModel`（97 行）→ `w2d.py`，每个文件单一职责。
2. **`type` 遮蔽已消除**：`base.py`、`c2.py`、`w2d.py`、`model.py` 共 17 处 `type` 参数全部重命名为 `conn_type`。
3. **`_auto_import` 幂等化**：添加 `_imported` 模块级哨兵，`ImportError` 改用 `logger.debug` 记录。
4. **`_LEVEL_TO_CLASS` 提升**：从 `create_model()` 函数体移至模块级，减少重复创建开销。
5. **零回归**：全部 5 个阶段各自运行全量测试，均为 1,472 passed, 36 xfailed。
6. **代码复审无 bug**：复审所有变更文件，未发现逻辑错误或遗漏。
