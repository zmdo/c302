## 阶段 2：`type` → `conn_type` 重命名

**目标：** 消除方法参数 `type` 对 Python 内建函数的遮蔽。

**变更范围：**

| 文件 | 方法 | 变更数 |
|------|------|--------|
| `base.py` | `get_exc_syn`, `get_inh_syn`, `get_elec_syn`, `_get_elec_syn_params` | 4 签名 + 全部方法体引用 |

| `w2d.py` | `get_exc_syn`, `get_inh_syn`, `get_elec_syn` | 3 签名 + 全部方法体引用 |
| `model.py` | `get_syn` | 1 签名 + docstring + 3 处调用 |

**安全性验证：** 所有调用点均使用位置参数，无 `type=` 关键字参数，重命名不影响调用侧。

---

## 阶段 3：优化 `_auto_import()`

**目标：** 防止重复扫描 + 记录导入失败信息。

**变更（`configs/__init__.py`）：**
- 添加模块级 `_imported = False` 哨兵
- `_auto_import()` 开头添加 `global _imported; if _imported: return; _imported = True`
- `except ImportError: pass` → `except ImportError: logger.debug("配置模块 %s 导入失败", name, exc_info=True)`

---

## 阶段 4：提升 `_LEVEL_TO_CLASS`

**目标：** 将字典从函数体移至模块级，避免每次调用 `create_model()` 时重新创建。

**变更（`factory/__init__.py`）：**
- `_LEVEL_TO_CLASS: dict[str, type] = {...}` 从 `create_model()` 内部移至模块顶部（import 语句之后）
- `create_model()` 函数体改为引用模块级变量
