## 等价性测试

`test_equivalence.py` 是项目的核心质量保证机制：

- **66 个基线组合** = 配置 × 参数层级（非所有组合有效）
- 每个基线为 JSON 文件，记录网络的关键数量特征
- 断言包括：种群数、投射数、连接数、突触类型、细胞类型等
- 基线存储在 `tests/fixtures/baselines/` 下
