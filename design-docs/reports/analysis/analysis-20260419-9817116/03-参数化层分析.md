## BioParameter 数据类

`bioparameter.py`（86 行）定义了参数封装：

```python
@dataclass
class BioParameter:
    name: str           # 参数名（如 "neuron_to_neuron_exc_syn_conductance"）
    value: str          # 值（如 "0.2 nS"，含单位）
    source: str         # 数据来源/参考文献
    certainty: str      # 确信度（"0" ~ "1"）
```

## YAML 参数加载

`loader.py`（149 行）支持 YAML 参数集加载，关键特性：
- `inherits` 字段支持参数继承（如 C1 继承 C）
- 自动解析 `custom_component_types_definitions` 引用
- 将 YAML 列表转换为 `BioParameter` 实例列表
