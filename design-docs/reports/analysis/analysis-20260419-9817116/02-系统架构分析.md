```
┌─────────────────────────────────────────┐
│              CLI (cli.py)               │  用户入口
├─────────────────────────────────────────┤
│         configs/  (16 脚本)             │  场景配置层
├─────────────────────────────────────────┤
│         generator/  (5 模块)            │  NeuroML 生成引擎
├──────────┬──────────┬───────────────────┤
│parameters│ readers/ │  simulation/      │  核心数据层
```

## 模块依赖关系

```
configs/{name}.py
  └── generator.__init__.generate()
        ├── parameters.get_parameter_set() → factory.create_model()
        │     └── factory/{level}.py → model.c302ModelPrototype
        ├── readers.get_reader() → {DataReader}.read_data()
        ├── population.create_populations()
        ├── connection.create_connections()
        ├── stimulation.create_stimulation()
        └── io.write_nml()

simulation.runner
  └── pyNeuroML (jNeuroML / NEURON)

visualization.{traces,heatmap,connectivity,graph}
  └── matplotlib / pyNeuroML
```

## 数据流

1. **参数加载**：`get_parameter_set(level)` → `factory.create_model(level)` → 创建细胞/突触/偏置电流模型
2. **数据读取**：`readers.get_reader(name)` → 读取连接组学电子表格 → 返回神经元列表和连接矩阵
3. **网络生成**：`generate()` 串联 population → connection → stimulation → io，输出 NeuroML 文档
4. **文件输出**：写出 `.net.nml`（网络）+ `LEMS_*.xml`（仿真参数）+ `cells/*.cell.nml`（多室细胞）
5. **仿真执行**：`runner.run_simulation()` 调用 jNeuroML 运行 LEMS 文件
6. **可视化**：读取仿真结果 `.dat` 文件，生成图表

## 关键设计模式

| 模式 | 应用位置 | 说明 |
|------|---------|------|
| 工厂方法 | `factory.create_model()` | 根据层级名称创建对应模型实例 |
| 模板方法 | `_ModelBase` 基类 | `create_models()` 定义骨架，子类重写具体步骤 |
| 注册表 | `configs/__init__.py` | `@register_config` 装饰器 + `_auto_import` 自动发现 |
| 注册表 | `readers/__init__.py` | 数据读取器注册与按名查找 |
| 策略 | `get_syn()` 方法 | 根据 `conn_type` + `pol` 分派到不同突触创建策略 |
| Mixin | `_GradedSynapse2Mixin` | 共享 GradedSynapse2 突触创建逻辑 |
