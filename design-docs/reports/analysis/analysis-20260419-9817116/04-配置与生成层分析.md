### 注册机制

- 每个配置文件使用 `@register_config("Name")` 装饰器自动注册
- `_auto_import()` 使用 `pkgutil.iter_modules` 扫描本包下所有模块
- 幂等哨兵 `_imported` 防止重复扫描
- `get_config(name)` 按名查找，首次使用时触发自动导入

### 配置脚本接口

每个配置脚本的 `setup()` 函数签名：

```python
def setup(
    parameter_set: str,           # 层级名称
    generate_flag: bool = False,  # 是否生成文件
    duration: float = 500.0,      # 仿真时长 (ms)
    dt: float = 0.05,             # 时间步长 (ms)
    target_directory: str = ".",  # 输出目录
    data_reader: str = "SpreadsheetDataReader",
    **kwargs,
) -> tuple[list, list, object, list, NeuroMLDocument]:
```

### generate() 入口函数

`generator/__init__.py` 的 `generate()` 是整个框架的核心函数，协调所有模块：

1. 加载参数集 → `params = get_parameter_set(level)`
2. 读取连接组数据 → `reader.read_data()`
3. 创建网络文档 → `NeuroMLDocument` + `Network`
4. 创建种群 → `population.create_populations()`
5. 创建连接 → `connection.create_connections()`（化学突触 + 电突触 + 肌肉连接）
6. 注入刺激 → `stimulation.create_stimulation()`
7. 写出文件 → `io.write_nml()` + `io.write_lems()`

### 连接创建

`connection.py` 处理三种连接类型：

| 连接类型 | 方法 | 说明 |
|---------|------|------|
| 神经元→神经元 | `create_neuron_to_neuron_connections()` | 化学突触 + 电突触 |
| 神经元→肌肉 | `create_neuron_to_muscle_connections()` | 化学突触 + 电突触 |
| 肌肉→肌肉 | `create_muscle_to_muscle_connections()` | 仅电突触 |

每种连接根据参数层级使用不同的突触类型（ExpTwoSynapse / GradedSynapse / GapJunction 等）。
