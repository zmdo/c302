## 项目定位

c302 是 OpenWorm 项目的子模块，用于生成秀丽隐杆线虫（*C. elegans*）302 个神经元的多尺度 NeuroML 2 网络模型。核心功能是将连接组（connectome）数据与参数化的细胞/突触模型组装为可仿真的 NeuroML 2 文件。

## 技术栈

| 层级 | 技术 |
|------|------|
| 语言 | Python 3（兼容 3.7+） |
| 核心依赖 | `pyNeuroML ≥ 1.3.15`、`cect ≥ 0.3.1`、`numpy`、`xlrd`、`xlwt` |
| 可选依赖 | `owmeta-core`、`owmeta`（语义数据库读取器） |
| 仿真后端 | jNeuroML（Java）、jNeuroML + NEURON |
| 模板引擎 | `airspeed`（Velocity 模板） |
| 数据格式 | NeuroML 2（.nml）、LEMS（.xml）、XLS、CSV、JSON |
| 可视化 | `matplotlib`、Graphviz（外部 CLI） |
| 版本 | `0.12.0` |
