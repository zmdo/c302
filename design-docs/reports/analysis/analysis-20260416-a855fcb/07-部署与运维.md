## 包安装

### setup.py

```python
name = "c302"
version = "0.12.0"  # 从 c302/__version__.py 读取
packages = ["c302"]
entry_points = {"console_scripts": ["c302 = c302.__init__:main"]}
install_requires = [
    "numpy", "xlrd", "xlwt",
    "pyNeuroML>=1.3.15",
    "WormNeuroAtlas",
    "cect>=0.3.1",
]
package_data = {"c302": ["*.xml", "data/*", "NeuroML2/*"]}
```

**问题**：
- `packages = ["c302"]` 硬编码单一包——引入子包后需改为 `find_packages()`
- 依赖版本无上界（如 `numpy` 不限版本，存在兼容性风险）
- `xlrd` + `xlwt` 是 `SpreadsheetDataReader` 的遗留依赖，cect 已提供更新的读取器
- `entry_points` 指向 `c302.__init__:main`，拆分后需更新

### 安装方式

```bash
pip install .          # 或
pip install -e .       # 开发模式
```

项目未使用 `pyproject.toml`（仍用 `setup.py`），不影响功能但不符合现代 Python 包规范。

## 依赖管理

| 依赖 | 用途 | 必需 | 备注 |
|------|------|------|------|
| `pyNeuroML ≥ 1.3.15` | NeuroML I/O + 仿真绑定 | 是 | 核心依赖 |
| `cect ≥ 0.3.1` | C. elegans 连接组工具箱 | 是 | 提供连接组数据读取 |
| `numpy` | 数值计算 | 是 | 可视化热图需要 |
| `xlrd` | 读取 .xls 文件 | 否（遗留） | 仅 SpreadsheetDataReader |
| `xlwt` | 写入 .xls 文件 | 否（未使用） | 可能是遗留 |
| `WormNeuroAtlas` | 虫体解剖数据 | 否（部分功能） | 仅 NeuroMLUtilities |
| `matplotlib` | 绘图 | 隐式 | 未列入 install_requires |
| `airspeed` | Velocity 模板 | 隐式 | 未列入 install_requires |
| `lxml` | XML 解析 | 隐式 | 未列入 install_requires |
| `owmeta-core` | 语义数据库 | 可选 | try/except 保护 |
| `owmeta` | OpenWorm 数据 | 可选 | try/except 保护 |

**问题**：`matplotlib`、`airspeed`、`lxml` 三个实际必需的依赖未列入 `install_requires`。

## 测试现状

### test.sh

唯一的测试入口，是一个 Shell 脚本，内容为执行一系列 Python 命令：

```bash
python -c "from c302 import ..."   # 导入测试
python c302/runAndPlot.py -...     # 集成测试（实际运行仿真）
```

**问题**：
- 🔴 无 pytest / unittest 框架
- 🔴 无单元测试（无法单独测试 `generate()` 的各步骤）
- 仅有集成测试（运行完整仿真流程）
- 测试时间长（依赖 jNeuroML Java 进程）
- 无测试覆盖率统计

### CI/CD

GitHub Actions 工作流定义在 `.github/workflows/`（4 个工作流），但主要执行 `test.sh` 的集成测试。
