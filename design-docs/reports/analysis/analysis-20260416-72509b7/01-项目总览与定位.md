## 项目简介

**c302** 是 [OpenWorm](http://www.openworm.org) 项目的核心子项目之一，是一个用于生成秀丽隐杆线虫（*Caenorhabditis elegans*）神经网络 [NeuroML 2](https://docs.neuroml.org) 模型的多尺度建模框架。

项目全称来源于线虫的 302 个神经元（hermaphrodite），框架能够基于真实的突触连接组数据，在多个生物学细节级别生成可仿真的神经网络模型。

**学术引用**：_c302: a multiscale framework for modelling the nervous system of Caenorhabditis elegans_, Padraig Gleeson et al., Phil. Trans. R. Soc. B 2018 373 20170379.

## 核心能力

| 能力 | 描述 |
|------|------|
| 多尺度建模 | 从简单积分放电神经元（Level A）到多室电导模型（Level D），4 个主要层级 + 6 个变体 |
| 连接组数据集成 | 支持 Excel 电子表格、CSV、owmeta 语义数据库三类数据源 |
| 网络配置灵活 | 15 种预置配置（全网络、前行回路、咽部回路、社交回路等） |
| NeuroML 2 输出 | 生成标准 NeuroML 2 / LEMS 文件，可在 jNeuroML 和 NEURON 中仿真 |
| 可视化 | 膜电位热图、钙浓度曲线、连接矩阵、Graphviz 网络图 |
| CLI 工具 | `python -m c302` 命令行入口，支持批量生成与测试 |
