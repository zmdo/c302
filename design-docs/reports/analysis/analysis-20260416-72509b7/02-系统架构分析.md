## 总体架构

c302 采用四层架构设计，从数据到仿真形成清晰的单向数据流：

```
┌─────────────────────────────────────────────────────────────┐
│                    仿真与可视化层                              │
│  jNeuroML / NEURON 仿真引擎                                  │
│  c302_utils.py (可视化)  runAndPlot.py (编排)                 │
│  gen_graph.py (网络图)                                       │
└──────────────────────────┬──────────────────────────────────┘
                           ↑ NeuroML 2 / LEMS 文件
┌──────────────────────────┴──────────────────────────────────┐
│                    网络生成层                                  │
│  c302/__init__.py::generate()                                │
│  - 种群创建 (Population)                                     │
│  - 突触连接 (Projection)                                     │
│  - 电突触 (ElectricalProjection)                             │
│  - 模拟突触 (ContinuousProjection)                           │
│  - 刺激输入 (InputList)                                      │
│  + c302_*.py 配置脚本 (setup() 函数)                         │
└──────────────────────────┬──────────────────────────────────┘
                           ↑ cells[], ConnectionInfo[]
┌──────────────────────────┴──────────────────────────────────┐
│                    参数化层                                    │
│  bioparameters.py                                            │
│  - BioParameter (单参数封装)                                  │
│  - ParameterisedModelPrototype (基类)                         │
│  - c302ModelPrototype (c302 扩展)                             │
│  + parameters_A/B/C/C0/C1/C2/D/D1/W2D.py (具体参数集)       │
└──────────────────────────┬──────────────────────────────────┘
                           ↑ read_data(), read_muscle_data()
┌──────────────────────────┴──────────────────────────────────┐
│                    数据读取层                                  │
│  ConnectomeReader.py (接口 + 常量)                            │
│  - SpreadsheetDataReader.py      (XLS 格式)                  │
│  - UpdatedSpreadsheetDataReader.py  (CSV 格式)               │
│  - UpdatedSpreadsheetDataReader2.py (修改版 CSV)             │
│  - OpenWormReader.py             (owmeta 数据库)             │
│  - White_*.py 适配器             (cect 外部库)               │
│  + data/ 目录（25 个数据文件）                                │
└─────────────────────────────────────────────────────────────┘
```

```
  ┌─────────────────────────────────────┐
  │    c302.__init__.generate()          │
  │                                      │
  │  1. 创建 NeuroMLDocument             │

  │  6. 创建电突触连接                     │

  │  9. 应用参数覆盖                      │
  └──────────────┬──────────────────────┘
                 │
                 ▼
  ┌──────────────────────────────┐
  │  write_to_file()              │
  │  - NeuroML (.net.nml)         │

                 │
                 ▼
  ┌──────────────────────────────┐
  │  runAndPlot.run_c302()        │
  │  - jNeuroML 仿真              │

  │  - 结果绘图                   │
  └──────────────────────────────┘
```

## 外部依赖清单

| 依赖 | 版本要求 | 用途 |
|------|---------|------|
| numpy | 无版本限制 | 数值计算 |

| xlwt | 无版本限制 | 写入 XLS 文件 |
| pyNeuroML | >= 1.3.15 | NeuroML 工具链（验证、仿真、绘图） |
| WormNeuroAtlas | 无版本限制 | 线虫神经图谱数据 |
| cect | >= 0.3.1 | C. elegans Connectome Toolbox（连接组工具箱） |
| neuroml (libNeuroML) | 由 pyNeuroML 引入 | NeuroML 文档对象模型 |
| airspeed | 由 pyNeuroML 引入 | Velocity 模板引擎 |
| lxml | 由 pyNeuroML 引入 | XML 解析与操作 |
| owmeta-core | 可选 | OpenWorm 语义元数据（细胞信息查询） |
| matplotlib | 由 pyNeuroML 引入 | 数据可视化 |

## 设计模式

| 模式 | 应用位置 | 说明 |
|------|---------|------|
| 工厂模式 | `load_data_reader()` | 按模块名动态加载数据读取器 |
| 策略模式 | `parameters_*.py` | 不同参数层级实现不同的细胞/突触创建策略 |
| 模板方法 | `c302ModelPrototype` | 基类定义骨架，子类实现 `set_default_bioparameters()` 等 |
| 适配器模式 | `White_*.py` | 将 cect 外部库的读取器适配到 c302 接口 |
| 外观模式 | `runAndPlot.run_c302()` | 封装生成→仿真→绘图的完整流程 |
| 装饰器模式 | 参数覆盖机制 | 通过正则匹配对连接权重进行运行时覆盖 |

## 扩展点

| 扩展点 | 方式 | 示例 |

| 新增数据源 | 实现 `read_data()` + `read_muscle_data()` | 参考 `SpreadsheetDataReader.py` |
