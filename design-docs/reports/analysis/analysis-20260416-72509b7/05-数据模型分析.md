## 数据模型概览

c302 不使用 ORM 或数据库，而是围绕 NeuroML 2 标准定义数据结构。核心数据模型分为三层：

1. **连接数据模型** — 描述生物连接组的中间表示
2. **NeuroML 文档模型** — 标准化的神经网络描述
3. **细胞模型定义** — 多层级的神经元/肌肉模型

## 1. 连接数据模型

### `ConnectionInfo` 类

所有数据读取器的标准输出格式，定义在 `ConnectomeReader.py`：

```
ConnectionInfo
├── pre_cell: str     # 突触前细胞名（如 "ADAL"）
├── post_cell: str    # 突触后细胞名（如 "AIBL"）
├── number: int       # 突触数量（权重）
├── syntype: str      # 突触类型
└── synclass: str     # 突触分类（神经递质）
```

### 突触类型枚举

| syntype 值 | 含义 | NeuroML 映射 |
|------------|------|-------------|
| `"Send"` | 化学突触（单向） | `Projection` + `Connection` |
| `"GapJunction"` | 电突触（双向） | `ElectricalProjection` |
| `"SendOrJunction"` | 不确定类型 | 按化学突触处理 |

### 突触分类枚举

| synclass 值 | 神经递质 | 性质 |
|-------------|---------|------|
| `"Acetylcholine"` | 乙酰胆碱 | 兴奋性 |
| `"GABA"` | γ-氨基丁酸 | 抑制性 |
| `"Glutamate"` | 谷氨酸 | 兴奋性 |
| `"Serotonin"` | 5-羟色胺 | 调节性 |
| `"Dopamine"` | 多巴胺 | 调节性 |
| `"Octopamine"` | 章鱼胺 | 调节性 |
| `"Generic_GJ"` | 通用缝隙连接 | 电耦合 |
| `"Generic_CS"` | 通用化学突触 | 兴奋性 |

### 细胞名称标准

| 类别 | 数量 | 命名格式 | 示例 |
|------|------|---------|------|
| 神经元 | 302 | 大写字母 + 数字 | ADAL, AIBR, VB1, DD6 |
| 体壁肌肉 | 95 | M[VD][LR]\d+ | MVL01, MDR24 |
| 特殊肌肉 | 2 | 大写名称 | MANAL, MVULVA |

## 2. NeuroML 文档模型

`generate()` 函数构建的核心文档结构：

```
NeuroMLDocument
├── id: str                     # 网络 ID（如 "c302_C_Pharyngeal"）
├── notes: str                  # 描述信息
├── iaf_cells[]                 # Level A: 积分放电细胞定义
├── includes[]                  # 外部文件引用 (IncludeType)
│   ├── cell_*.xml              # 细胞模型定义
│   ├── custom_synapses.xml     # 突触类型定义
│   └── *.cell.nml              # 个体细胞形态文件
├── networks[]
│   └── Network
│       ├── populations[]       # 种群列表
│       │   └── Population
│       │       ├── component: str        # 引用细胞模型
│       │       └── instances[]           # 实例列表
│       │           └── Instance
│       │               └── location: Location(x, y, z)
│       ├── projections[]       # 化学突触投射
│       │   └── Projection
│       │       ├── presynaptic_population: str
│       │       ├── postsynaptic_population: str
│       │       ├── synapse: str          # 突触模型 ID
│       │       └── connections[]         # Connection / ConnectionWD
│       ├── electrical_projections[]  # 电突触投射
│       │   └── ElectricalProjection
│       │       └── electrical_connection_instance_ws[]
│       └── continuous_projections[]  # 模拟突触投射
│           └── ContinuousProjection
│               └── continuous_connection_instance_ws[]
├── pulse_generators[]          # 脉冲电流刺激
├── sine_generators[]           # 正弦波刺激
└── input_lists[]               # 输入列表（刺激→细胞映射）
```

### LEMS 信息字典

`generate()` 返回的 `lems_info` 字典，用于生成仿真配置文件：

```python
lems_info = {
    "reference":    "c302_C_Pharyngeal",    # 仿真引用名
    "duration":     "1000",                  # 仿真时长 (ms)
    "dt":           "0.05",                  # 时间步长 (ms)
    "comment":      "...",                   # 描述信息
    "report":       "...",                   # 报告文本
    "target_directory": "examples/",         # 输出目录
    "sim_plots":    {...},                   # 绘图配置
    "sim_outputs":  {...},                   # 输出变量配置
}
```

## 3. 细胞模型定义

### 模型层级

| Level | 细胞模型 | 定义文件 | 复杂度 |
|-------|---------|---------|--------|
| A | `IafCell` (积分放电) | 内联定义 | 最简单，无真实离子通道 |
| B | 自定义 IafCell + activity 变量 | `cell_B.xml` | 增加"活性"状态变量 |
| C | 单室电导模型 (HH 通道) | `cell_C.xml` | K/Na/Ca 离子通道，Hodgkin-Huxley |
| C0 | Level C 变体 | `cell_C.xml` + 参数调整 | 不同通道参数 |
| C1 | Level C 变体 | `cell_C.xml` + 参数调整 | 简化通道参数 |
| C2 | Level C 变体 | `cell_C.xml` + 参数调整 | 最多参数调整 |
| D | 多室电导模型 | `*_D.cell.nml` (302 个, `examples/cells/`) + 6 个参考模型 (`cells/`) | 真实形态 + 通道分布 |
| D1 | Level D 简化变体 | `*.cell.nml` 子集 | 简化参数 |
| W2D | 发育阶段 (L2 幼虫) | `cell_W2D.xml` | L2 阶段参数 |

### Level C 细胞模型结构 (cell_C.xml)

```
GenericCell (单室)
├── capacitance: 3.0 pF
├── Leak conductance: ~0.005 nS
├── K channel
│   ├── conductance: ~1.0 nS
│   └── activation gate: n (Boltzmann)
├── Na channel (部分变体)
│   ├── conductance: ~0.1 nS
│   ├── activation gate: m (Boltzmann)
│   └── inactivation gate: h (Boltzmann)
├── Ca channel
│   ├── conductance: ~0.5 nS
│   └── activation gate: e (Boltzmann)
└── Ca dynamics
    └── FixedFactorConcentrationModel
```

### 突触模型

| 模型 | NeuroML 类型 | 用途 |
|------|-------------|------|
| `ExpTwoSynapse` | 双指数突触 | 化学突触（兴奋性/抑制性） |
| `GapJunction` | 缝隙连接 | 电突触 (Level B+) |
| `GradedSynapse` | 分级突触 | 模拟突触 (Level C+) |
| `SilentSynapse` | 静默突触 | Level A 的伪缝隙连接 |

### NeuroML2/ 目录文件统计

| 类别 | 数量 | 说明 |
|------|------|------|
| 神经元单室模型 (.cell.nml) | 303 | 每个神经元一个文件（Level C/D） |
| 离子通道定义 | 1 | LeakConductance.channel.nml |
| OMV 测试 | 1 | .test.validate.omt |
| 辅助脚本 | 1 | printNML2Info.py |
| **合计** | 306 | 目录内全部文件（其中 304 个 .nml） |

> 注：6 个多室参考模型（ADAL_D、AIBL_D、DB5_D、I1L_D、I3_D、PVCR_D）位于 `cells/` 目录而非 NeuroML2/。

## 4. 输出文件格式

### .net.nml 文件

标准 NeuroML 2 XML 格式网络文件，包含完整的种群、连接、刺激定义。

命名规则：`c302_{ParamSet}_{Config}.net.nml`

示例：`c302_C_Pharyngeal.net.nml`

### LEMS XML 文件

LEMS 仿真配置文件，指定仿真时长、时间步长、输出变量。

命名规则：`LEMS_c302_{ParamSet}_{Config}.xml`

通过 Airspeed 模板引擎从 `LEMS_c302_TEMPLATE.xml` 生成。

### 输出变量

| 变量路径 | 含义 |
|---------|------|
| `{pop}/0/GenericCell/v` | 膜电位 (mV) |
| `{pop}/0/GenericCell/caConc` | 钙浓度 |
| `{pop}/0/GenericCell/activity` | 活性变量 (Level B) |
