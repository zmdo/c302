## 参数化系统概览

c302 的参数化系统是框架的核心设计之一，通过层级继承实现从简单到复杂的多尺度建模。

### 类继承关系

```
ParameterisedModelPrototype (bioparameters.py)
└── c302ModelPrototype (bioparameters.py)
    ├── ParameterisedModel (parameters_A.py)     # Level A
    ├── ParameterisedModel (parameters_B.py)     # Level B → 继承 A
    ├── ParameterisedModel (parameters_C.py)     # Level C
    │   ├── ParameterisedModel (parameters_C0.py)    # C0
    │   ├── ParameterisedModel (parameters_C1.py)    # C1
    │   └── ParameterisedModel (parameters_C2.py)    # C2
    ├── ParameterisedModel (parameters_D.py)     # Level D
    │   └── ParameterisedModel (parameters_D1.py)    # D1
    ├── ParameterisedModel (parameters_BC1.py)   # BC1 (混合)
    └── ParameterisedModel (parameters_W2D.py)   # W2D (发育阶段)
```

## 1. 基础类

### `BioParameter` — 单参数封装

```python
class BioParameter:
    name: str        # 参数名（如 "leak_cond_density"）
    value: str       # 参数值（如 "0.005 mS_per_cm2"）
    source: str      # 来源说明
    certainty: str   # 确定性等级
```

### `ParameterisedModelPrototype` — 参数集基类

| 方法 | 用途 |
|------|------|
| `add_bioparameter(name, value, source, certainty)` | 添加生物参数 |
| `get_bioparameter(name)` | 按名称获取参数值 |
| `set_bioparameter(name, value, source, certainty)` | 更新参数值 |
| `bioparameter_info(html=False)` | 输出所有参数信息 |

### `c302ModelPrototype` — c302 扩展基类

| 方法 | 用途 |
|------|------|
| `is_level_A()` / `is_level_B()` / `is_level_C()` / `is_level_D()` | 层级判断 |
| `get_syn(pre, post, synclass, syntype)` | 获取突触模型 ID |
| `create_n_connection_synapse(n, syn, ...)` | 创建 N 连接突触（多突触计数建模） |
| `is_elec_conn(synclass)` | 判断是否为电突触 |
| `is_analog_conn(synclass)` | 判断是否为模拟突触 |
| `is_nonneuroml_conn(synclass)` | 判断是否为非 NeuroML 连接 |

## 2. 参数层级详解

### Level A — 积分放电模型

| 参数 | 代码行数 | 说明 |
|------|---------|------|
| 文件 | `parameters_A.py` | 365 行 |
| 细胞模型 | `IafCell` | 内联定义，无形态 |
| 突触 | `ExpTwoSynapse` | 事件驱动，双指数 |
| 缝隙连接 | 伪实现 (SilentSynapse) | 零电导，不传递电流 |
| 生物真实性 | 低 | 倾向过度兴奋 |

关键参数：

| 参数名 | 典型值 | 含义 |
|--------|--------|------|
| `cell_leak_cond_density` | 0.005 mS_per_cm2 | 漏电导密度 |
| `cell_thresh` | -30 mV | 发放阈值 |
| `cell_C` | 3 pF | 膜电容 |
| `inh_syn_conductance` | 0.2 nS | 抑制性突触电导 |
| `exc_syn_conductance` | 0.5 nS | 兴奋性突触电导 |
| `elec_syn_gbase` | 0 nS | 电突触电导（Level A 为 0） |

### Level B — 带活性变量的积分放电

| 参数 | 说明 |
|------|------|
| 文件 | `parameters_B.py` |
| 继承 | Level A 的 IafCell 结构 |
| 新增 | `activity` 状态变量 |
| 细胞定义 | `cell_B.xml` |
| 缝隙连接 | **真实** GapJunction（电流 = g × ΔV） |
| 改进 | 电突触能传递真实电流 |

### Level C — 单室 Hodgkin-Huxley 电导模型

| 参数 | 代码行数 | 说明 |
|------|---------|------|
| 文件 | `parameters_C.py` | 529 行 |
| 细胞定义 | `cell_C.xml` | 单室模型 |
| 离子通道 | K, Na (可选), Ca | Hodgkin-Huxley 门控 |
| 钙动力学 | FixedFactorConcentrationModel | 钙浓度追踪 |
| 突触 | 双指数化学突触 + 真实缝隙连接 | — |

Level C 关键离子通道参数：

| 通道 | 参数 | 含义 |
|------|------|------|
| K channel | `neuron_k_channel_cond_density` | 钾通道电导密度 |
| Ca channel | `neuron_ca_boyle_cond_density` | 钙通道电导密度 |
| Leak | `neuron_leak_cond_density` | 漏电导密度 |

### Level C 变体对比

| 变体 | 行数 | 关键差异 |
|------|------|---------|
| C0 (`parameters_C0.py`) | 607 | 更多离子通道参数调整，肌肉参数独立定义 |
| C1 (`parameters_C1.py`) | 260 | 简化参数集 |
| C2 (`parameters_C2.py`) | 1,586 | 最详细的参数集，包含大量按细胞类型区分的覆盖 |

### Level D — 多室电导模型

| 参数 | 说明 |
|------|------|
| 文件 | `parameters_D.py`（524 行） |
| 细胞定义 | 302 个 `_D.cell.nml` 文件（`examples/cells/`，每个神经元独立形态），6 个参考模型（`cells/`） |
| 形态 | 真实的多室形态（从实验数据重建） |
| 通道分布 | 按区段分布离子通道 |
| 已知问题 | 高内阻问题 (GitHub issue #71) |

## 3. 配置脚本

每个配置脚本定义一个 `setup()` 函数，指定包含的细胞、肌肉和刺激：

| 配置脚本 | 行数 | 网络规模 | 描述 |
|---------|------|---------|------|
| `c302_Full.py` | ~50 | 全部 302 神经元 | 完整连接组 |
| `c302_FW.py` | 254 | ~35 神经元 + 肌肉 | 前行运动回路 |
| `c302_IClamp.py` | ~40 | 2 神经元 + 1 肌肉 | 电流钳测试 |
| `c302_IClampMuscle.py` | ~40 | 肌肉测试 | 肌肉响应测试 |
| `c302_Muscles.py` | 255 | ~40 神经元 + 肌肉 | 神经肌肉控制 |
| `c302_MusclesSine.py` | 266 | 肌肉 + 正弦刺激 | 节律性驱动测试 |
| `c302_MuscleTest.py` | ~40 | 肌肉测试 | 单肌肉响应 |
| `c302_Oscillator.py` | ~60 | ~10 神经元 | 振荡回路 |
| `c302_OscillatorM.py` | ~60 | 振荡 + 肌肉 | 振荡驱动肌肉 |
| `c302_Pharyngeal.py` | ~80 | ~20 神经元 | 咽部摄食回路 |
| `c302_RIA.py` | ~30 | RIA 神经元 | 单细胞测试 |
| `c302_Social.py` | ~50 | ~7 神经元 | 社交决策回路 |
| `c302_Syns.py` | ~60 | 所有有连接的神经元 | 突触连接测试 |
| `c302_TapWithdrawal.py` | 474 | ~30 神经元 + 肌肉 | 触碰退缩反射 |
| `c302_TargetMuscle.py` | ~40 | 特定肌肉 | 目标肌肉测试 |

### 配置脚本结构

每个 `c302_*.py` 文件遵循统一结构：

```python
# 1. 定义常量
DATA_READER = "c302.SpreadsheetDataReader"  # 或其他读取器

# 2. 定义细胞列表
cells = ["ADAL", "PVCL", ...]

# 3. 定义 setup() 函数
def setup(parameter_set, ...):
    # 调用 c302.generate() 并返回结果
    exec("from c302.parameters_%s import ParameterisedModel" % parameter_set)
    params = ParameterisedModel()
    # ... 配置参数覆盖
    return c302.generate(net_id, params, cells=cells, ...)

# 4. main() 入口
if __name__ == "__main__":
    # 解析参数并调用 setup()
```
