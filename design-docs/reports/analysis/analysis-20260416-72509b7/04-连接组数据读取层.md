## 读取器概览

c302 支持多种连接组数据源，通过统一的读取器接口加载。所有读取器实现两个核心方法：

- `read_data(include_nonconnected_cells=False)` → `(cells[], connections[])`
- `read_muscle_data()` → `(neurons[], muscles[], connections[])`

| 读取器 | 行数 | 数据源 | 格式 |
|--------|------|--------|------|
| `SpreadsheetDataReader.py` | ~120 | CElegansNeuronTables.xls | XLS |
| `UpdatedSpreadsheetDataReader.py` | ~230 | herm_full_edgelist.csv | CSV |
| `UpdatedSpreadsheetDataReader2.py` | ~240 | herm_full_edgelist_MODIFIED.csv | CSV |
| `OpenWormReader.py` | 221 | owmeta 语义数据库 | Bundle |
| `White_whole.py` | ~30 | cect.WhiteDataReader (whole) | 适配 |
| `White_A.py` | ~30 | cect.WhiteDataReader (adult) | 适配 |
| `White_L4.py` | ~30 | cect.WhiteDataReader (L4 larva) | 适配 |

## 1. `ConnectomeReader.py` — 基础模块

这不是一个抽象基类，而是提供连接组相关的常量定义和工具函数。

### 核心数据类

```python
class ConnectionInfo:
    def __init__(self, pre_cell, post_cell, number, syntype, synclass):
        ...
```

| 字段 | 类型 | 含义 |
|------|------|------|
| `pre_cell` | str | 突触前细胞名称 |
| `post_cell` | str | 突触后细胞名称 |
| `number` | int | 突触数量 |
| `syntype` | str | 突触类型："Send", "GapJunction" 等 |
| `synclass` | str | 突触分类："Acetylcholine", "GABA", "Generic_GJ" 等 |

### 关键常量

| 常量 | 数量 | 说明 |
|------|------|------|
| `PREFERRED_NEURON_NAMES` | 302 | 标准神经元名称列表 |
| `PREFERRED_MUSCLE_NAMES` | 96 | 标准肌肉名称列表（含 MANAL, MVULVA） |
| `BODY_WALL_MUSCLE_NAMES` | 从 cect 导入 | 体壁肌肉子集 |

### 工具函数

| 函数 | 用途 |
|------|------|
| `remove_leading_index_zero(cell)` | 名称规范化：VB01 → VB1 |
| `is_muscle(cell)` | 判断是否为肌肉细胞 |
| `is_neuron(cell)` | 判断是否为神经元 |
| `check_neurons(cells)` | 校验细胞列表，与标准名称比对 |
| `analyse_connections(cells, conns)` | 输出连接统计信息 |

## 2. `SpreadsheetDataReader.py` — XLS 读取器

读取遗留的 Excel 电子表格数据（White et al. 连接组）。

### 数据源

`data/CElegansNeuronTables.xls`，包含两个工作表：

| 工作表 | 内容 |
|--------|------|
| Sheet 1 | 神经元→神经元连接（pre, post, synapse count, type, class） |
| Sheet 2 | 神经元→肌肉连接 |

### 突触分类映射

| syntype 原始值 | 映射含义 |
|---------------|---------|
| `"Send"` | 化学突触（单向） |
| `"GapJunction"` | 电突触（双向） |

| synclass 原始值 | 神经递质 |
|----------------|---------|
| `"Acetylcholine"` | 乙酰胆碱（兴奋性） |
| `"GABA"` | γ-氨基丁酸（抑制性） |
| `"Generic_GJ"` | 通用缝隙连接 |

## 3. `UpdatedSpreadsheetDataReader.py` — CSV 读取器

读取更新版的 CSV 格式连接组数据。

### 数据源

`data/herm_full_edgelist.csv`（雌雄同体连接组完整边列表）

### 特殊逻辑

- **肌肉名称转换**：`vBWML05` → `MVL05` 格式
- **突触极性推断**：DD/VD 类神经元的突触前连接推断为 GABA，其余为 Acetylcholine
- **连接过滤**：排除非神经元→非神经元的连接

### 辅助函数

| 函数 | 用途 |
|------|------|
| `get_syntype(row)` | 从 CSV 行提取突触类型 |
| `get_synclass(row)` | 推断突触分类（基于突触前细胞类型） |
| `parse_row(row)` | 解析 CSV 行为结构化数据 |
| `get_old_muscle_name(new_name)` | 新旧肌肉名称映射 |

## 4. `UpdatedSpreadsheetDataReader2.py` — 修改版 CSV 读取器

与 `UpdatedSpreadsheetDataReader.py` 结构相同，但使用修改版数据源。

### 与前版差异

| 差异 | UpdatedSpreadsheetDataReader | UpdatedSpreadsheetDataReader2 |
|------|------------------------------|-------------------------------|
| 数据源 | herm_full_edgelist.csv | herm_full_edgelist_MODIFIED.csv |
| 连接过滤 | 排除非神经元→非神经元 | 排除两端都不是神经元的连接；允许肌肉→肌肉 |

## 5. `OpenWormReader.py` — owmeta 读取器

通过 owmeta-core（OpenWorm 语义 Web 数据库）读取连接组数据。

### 架构

```python
class OpenWormReader:
    def __init__(self):
        self._connections = None  # 缓存
        self._muscles = None      # 缓存

    def read_data(self, include_nonconnected_cells=False):
        # 查询 owmeta Bundle → 获取 Neuron 对象 → 提取连接
        ...

    def read_muscle_data(self):
        # 查询 BodyWallMuscle → 提取肌肉连接
        ...
```

### 缓存策略

连接数据在首次查询后缓存到实例变量 `_connections` / `_muscles`，避免重复的 owmeta Bundle 查询。

### 依赖

- `owmeta_core.Bundle` — 数据包加载
- `owmeta_core.Context` — 查询上下文
- `owmeta.Neuron` / `owmeta.BodyWallMuscle` / `owmeta.Worm` — 生物实体类

## 6. `White_*.py` — cect 适配器

三个轻量适配器文件，将 cect 外部库的 WhiteDataReader 适配到 c302 接口。

| 适配器 | 数据集 | 说明 |
|--------|--------|------|
| `White_whole.py` | White et al. 完整数据 | 全生命周期连接组 |
| `White_A.py` | White et al. 成虫数据 | 成虫阶段 |
| `White_L4.py` | White et al. L4 幼虫数据 | L4 发育阶段 |

### 适配模式

```python
# White_whole.py 示例结构
from cect.WhiteDataReader import WhiteDataReader

reader = WhiteDataReader("whole")

def read_data(include_nonconnected_cells=False):
    return reader.read_data(include_nonconnected_cells)

def read_muscle_data():
    return reader.read_muscle_data()
```

## 数据读取器选择机制

在 `__init__.py` 中通过 `load_data_reader()` 工厂函数按名称动态加载：

```python
def load_data_reader(data_reader_name):
    # 先尝试 cect 包: "cect.{name}"
    # 再尝试 c302 包: "c302.{name}"
    # 通过 importlib 动态导入
```

各配置脚本（c302_*.py）可指定不同的 `DATA_READER`，例如：
- `c302_FW.py` → `"cect.readers.UpdatedSpreadsheetDataReader2"`
- `c302_Pharyngeal.py` → `"c302.SpreadsheetDataReader"`（默认）
