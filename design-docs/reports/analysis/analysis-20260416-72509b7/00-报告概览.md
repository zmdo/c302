## 核心发现

1. **项目定位明确**：c302 是 OpenWorm 项目的神经网络建模框架，基于真实秀丽隐杆线虫连接组数据生成多尺度 NeuroML 2 模型
2. **四层架构清晰**：数据层 → 参数层 → 生成层 → 仿真层，各层职责明确
3. **主模块集中度高**：`__init__.py` 包含 1,867 行代码，承担了网络生成的核心逻辑
4. **多数据源支持**：支持 Excel 电子表格、CSV 文件、owmeta 语义数据库三类数据源
5. **参数化层级设计**：从简单积分放电（Level A）到多室电导模型（Level D），逐级增加生物真实性
6. **仓库已重组**：源码已迁移至 `project/` 目录，CI 工作流已同步更新
