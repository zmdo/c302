## 1. `__init__.py` — 网络生成核心

这是整个框架的核心模块，承担了 NeuroML 网络文件的完整生成流程。

### 关键函数

| 函数 | 行为 |
|------|------|
| `generate(net_id, params, cells, cells_to_plot, ...)` | 核心函数：创建 NeuroML 文档，组装种群/连接/输入，返回文档对象 |
| `process_args()` | CLI 参数解析，返回 (reference, params, data_reader, ...) |
| `load_data_reader(data_reader_name)` | 工厂函数：按名称动态导入数据读取器模块 |
| `get_cell_names_and_connection(data_reader, ...)` | 通过读取器获取细胞列表和神经元间连接 |
| `get_cell_muscle_names_and_connection(data_reader, ...)` | 获取肌肉连接数据 |
| `_get_cell_info(cell, worm)` | 从 owmeta 查询细胞元数据（类型、神经递质、受体） |
| `write_to_file(nml_doc, lems_info, ...)` | 写出 .net.nml 和 LEMS .xml 文件，执行验证 |
| `add_new_input(nml_doc, ...)` | 向网络添加脉冲电流刺激 |
| `add_new_sinusoidal_input(nml_doc, ...)` | 向网络添加正弦波刺激 |
| `get_muscle_position(muscle, index)` | 计算肌肉细胞 3D 空间位置 |
| `main()` | CLI 入口点（通过 `c302` 命令调用） |
| `parse_list_arg(arg)` / `parse_dict_arg(arg)` | 命令行参数解析辅助 |

### `generate()` 函数流程

```
1. 创建 NeuroMLDocument
2. 加载细胞模型 (Level 相关: IafCell / cell_B.xml / cell_C.xml / 多室模型)
3. 创建 Network 和 Population
4. 为每个细胞创建 Instance 并分配 3D 位置
5. 遍历连接数据:
   5a. 化学突触 → Projection + Connection/ConnectionWD
   5b. 电突触   → ElectricalProjection + ElectricalConnectionInstanceW
   5c. 模拟突触 → ContinuousProjection + ContinuousConnectionInstanceW
6. 应用连接权重覆盖 (connection_number_override, vmax_override 等)
7. 创建肌肉种群和连接 (如果配置包含肌肉)
8. 添加刺激输入 (PulseGenerator / SineGenerator)
9. 构建 LEMS 信息字典 (仿真参数、输出、绘图)
10. 返回 (nml_doc, nml_file_name, lems_info)
```

### 连接类型处理

| 连接类型 | NeuroML 元素 | 判断方法 |
|---------|-------------|---------|
| 化学突触 | `Projection` + `Connection` / `ConnectionWD` | `not is_elec_conn() and not is_analog_conn()` |
| 电突触（缝隙连接） | `ElectricalProjection` + `ElectricalConnectionInstanceW` | `is_elec_conn()` |
| 模拟突触（分级突触） | `ContinuousProjection` + `ContinuousConnectionInstanceW` | `is_analog_conn()` |
| 非 NeuroML 类型 | 跳过 | `is_nonneuroml_conn()` |

### 参数覆盖机制

`generate()` 支持多种运行时覆盖：

- `connection_number_override`: 按正则匹配覆盖连接权重
- `connection_number_scaling`: 连接数缩放因子
- `vmax_override`: 最大电压覆盖
- `custom_inputs`: 自定义电流注入参数
- `duration`, `dt`, `target_directory`: 仿真参数

## 2. `c302_utils.py` — 可视化与分析

### 关键函数

| 函数 | 用途 |
|------|------|
| `plot_c302_results(lems_results, config, ...)` | 主绘图函数：生成膜电位/活性热图、轨迹图 |
| `generate_conn_matrix(nml_file, ...)` | 从 .net.nml 文件生成连接矩阵热图 |
| `generate_traces_plot(lems_results, ...)` | 单细胞电压轨迹绘图 |
| `natsort(l)` | 自然排序（处理 VB1, VB2, ... VB11 排序问题） |
| `_show_conn_matrix(matrix, cells, ...)` | 内部热图渲染 |

### 绘图输出类型

- **膜电位热图**：所有细胞的膜电位随时间变化，颜色编码
- **活性/钙浓度热图**：细胞活性水平随时间变化
- **连接矩阵**：兴奋性/抑制性/电突触连接强度矩阵
- **单细胞轨迹**：指定细胞的详细电压-时间曲线

## 3. `runAndPlot.py` — 仿真编排

### 核心函数

`run_c302(config, parameter_set, prefix, ...)` — 端到端工作流：

```
1. 动态导入 c302_{config}.py 模块
2. 调用 setup() 获取 (nml_doc, nml_file_name, lems_info)
3. 调用 write_to_file() 写出文件
4. 选择仿真后端:
   - jNeuroML (默认)
   - jNeuroML + NEURON (-jnrn 参数)
5. 运行仿真
6. 调用 plot_c302_results() 绘图
```

### CLI 用法

```bash
python runAndPlot.py -pharC          # 咽部回路, 参数 C
python runAndPlot.py -fullA -jnrn    # 全网络, 参数 A, NEURON 后端
python runAndPlot.py -all            # 生成所有配置组合
python runAndPlot.py -oscC1          # 振荡回路, 参数 C1
```

支持的快捷参数格式: `-{config}{paramSet}`，例如 `-pharC` = Pharyngeal + Level C。

## 4. `gen_graph.py` — 网络图可视化

从 NeuroML 网络文件生成 Graphviz DOT 格式的网络拓扑图。

### 视觉编码

| 节点类型 | 颜色 |
|---------|------|
| 运动神经元 | slategray1 |
| 肌肉 | darkolivegreen3 |
| 其他神经元 | thistle2 |

| 连接类型 | 样式 |
|---------|------|
| 化学突触（兴奋性） | 实线 |
| 化学突触（抑制性） | 红色实线 |
| 电突触（缝隙连接） | 虚线 |
