## 安装方式

### 开发安装

```bash
git clone https://github.com/openworm/c302.git
cd c302/project
pip install .
```

### 可选依赖（owmeta）

```bash
owm bundle remote --user add ow 'https://raw.githubusercontent.com/openworm/owmeta-bundles/master/index.json'
```

### 仿真后端（NEURON）

```bash
pip install neuron  # Mac/Linux
```

> Windows 用户需使用 Python 3.10 虚拟环境（owmeta 不支持更新版本）。

### 入口点

安装后提供 `c302` 命令行工具：

```python
# setup.py
entry_points={"console_scripts": ["c302 = c302.__init__:main"]}
```

## CI/CD 工作流

### 工作流清单（4 个）

| 工作流 | 文件 | 触发条件 | 运行环境 |
|--------|------|---------|---------|
| OMV tests | `ci.yml` | push/PR → master, development, experimental, ow* | ubuntu-latest |
| Non-OMV-tests | `non_omv.yml` | push/PR → master, development, experimental, ow* | ubuntu-latest, macos-latest |
| Test latest cect | `test_cect_dev.yml` | push/PR + 月度定时 (每月1日 01:01) | ubuntu-latest, macos-latest |
| Upload Python Package | `python-publish.yml` | release published | ubuntu-latest |

### 1. OMV tests (`ci.yml`)

使用 Open Source Brain Model Validation (OMV) 框架进行模型验证。

| 配置 | 值 |
|------|------|
| Python 版本 | 3.10, 3.13 |
| 测试引擎 | jNeuroML, jNeuroML_NEURON, jNeuroML_validate |
| 矩阵策略 | fail-fast: false（不中断其他任务） |
| 安装方式 | `pip install ./project` |

测试流程：
1. 安装 OMV 和科学计算依赖（scipy, sympy, matplotlib, cython, pandas, tables）
2. 运行 `omv all -V --engine={engine}`
3. 安装 c302 包
4. 输出测试列表

### 2. Non-OMV-tests (`non_omv.yml`)

直接运行 Python 脚本测试。

| 配置 | 值 |
|------|------|
| Python 版本 | 3.10, 3.12, 3.13 |
| 平台 | ubuntu-latest, macos-latest |
| macOS 排除 | Python 3.8 |

测试流程：
1. 安装 HDF5（macOS）
2. 安装 OMV
3. `pip install ./project`
4. 运行示例：`cd project/c302 && python c302_IClamp.py A`
5. 安装 NEURON
6. 运行完整测试：`cd project && ./test.sh`

### 3. Test latest cect (`test_cect_dev.yml`)

测试与 cect 开发版本的兼容性。

| 配置 | 值 |
|------|------|
| Python 版本 | 3.13 |
| 定时触发 | 每月 1 日 01:01 UTC |
| cect 来源 | `git+https://github.com/pgleeson/ConnectomeToolbox@development` |

### 4. Upload Python Package (`python-publish.yml`)

发布到 PyPI。

| 配置 | 值 |
|------|------|
| 触发 | GitHub Release 发布 |
| 构建 | `cd project && python -m build` |
| 发布 | `pypa/gh-action-pypi-publish@release/v1` |
| 认证 | `secrets.PYPI_API_TOKEN` |

## 依赖管理

### 直接依赖（setup.py）

| 包 | 版本要求 | 用途 |
|------|---------|------|
| numpy | 无限制 | 数值计算 |
| xlrd | 无限制 | 读取 .xls 文件 |
| xlwt | 无限制 | 写入 .xls 文件 |
| pyNeuroML | >= 1.3.15 | NeuroML 工具链 |
| WormNeuroAtlas | 无限制 | 线虫神经图谱 |
| cect | >= 0.3.1 | C. elegans Connectome Toolbox |

### 间接依赖（通过 pyNeuroML 引入）

| 包 | 用途 |
|------|------|
| neuroml (libNeuroML) | NeuroML 文档对象模型 |
| airspeed | Velocity 模板引擎 |
| lxml | XML 解析 |
| matplotlib | 可视化 |

### 开发依赖

| 包 | 用途 |
|------|------|
| ruff | 代码格式化和静态检查 |
| scipy, sympy | 科学计算（CI 中使用） |
| neuron | NEURON 仿真器（可选） |

## 包数据

`setup.py` 声明的包数据：

```python
package_data={"c302": ["*.xml", "data/*", "NeuroML2/*"]}
```

包含：
- `*.xml` — LEMS 模板、自定义组件定义
- `data/*` — 连接组数据文件（25 个）
- `NeuroML2/*` — 细胞模型文件（304 个 .nml）

## 目录结构约定

| 目录 | 用途 | 运行时生成 |
|------|------|-----------|
| `project/examples/` | 预生成的网络文件和示例 | 部分由 test.sh 生成 |
| `project/c302/data/` | 连接组数据（只读） | 否 |
| `project/c302/NeuroML2/` | 细胞模型定义（只读） | 否 |
