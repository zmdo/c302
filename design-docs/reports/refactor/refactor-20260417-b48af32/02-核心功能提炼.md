## 功能全景

从 16,260 行原代码中提炼出 c302 的核心功能链：

```
用户输入                    核心流程                         输出
─────────     ──────────────────────────────────     ──────────
参数集名称 ──→ 加载参数集 ──→ 创建模型组件          ──→ .net.nml
配置名称   ──→ 加载配置   ──→ 读取连接组数据        ──→ LEMS_*.xml
CLI 参数   ──→ 解析参数   ──→ 创建种群/连接/刺激    ──→ 仿真结果
                            ──→ 写出 NeuroML 文件    ──→ 可视化图表
                            ──→ 运行仿真
                            ──→ 绘制结果
```

## 功能分解（6 大功能域）

### 功能域 1：连接组数据读取

**职责**：从不同数据源读取线虫连接组，输出统一格式。

**输入**：数据文件（CSV/XLS）或外部库（cect/owmeta）
**输出**：`(cells: list[str], conns: list[ConnectionInfo])`

**原代码实现**：8 个读取器模块，1,837 行

| 读取器 | 数据源 | 行数 | 重写价值 |
|--------|--------|------|----------|
| `SpreadsheetDataReader` | `CElegansNeuronTables.xls` | 155 | 保留 |
| `UpdatedSpreadsheetDataReader` | `herm_full_edgelist.csv` | 271 | 合并 |
| `UpdatedSpreadsheetDataReader2` | `herm_full_edgelist_MODIFIED.csv` | 276 | 合并（与上合并） |
| `OpenWormReader` | owmeta Bundle | 288 | 延后（可选依赖） |
| `White_whole` | `cect.WhiteDataReader` | 38 | 合并 |
| `White_A` | `cect.WhiteDataReader` | 38 | 合并（与上合并） |
| `White_L4` | `cect.WhiteDataReader` | 38 | 合并（与上合并） |
| `ConnectomeReader` | 内置常量 | 733 | 拆分（常量 vs 工具） |

**重写后预期**：3 个读取器 + 1 个基础模块 + 1 个 ABC，约 500-700 行

**关键数据结构**：

```python
# 原代码 ConnectionInfo（ConnectomeReader.py L42-76）
class ConnectionInfo:
    pre_cell: str       # 突触前细胞名称
    post_cell: str      # 突触后细胞名称
    number: int         # 连接数量
    syntype: str        # 突触类型（"Send" 化学突触 / "GapJunction" 电突触）
    synclass: str       # 突触分类（如 "GABA", "Acetylcholine"）
```

此数据结构设计合理，重写时保留并增加类型注解。

### 功能域 2：参数化系统

**职责**：定义不同抽象层级的细胞/突触/连接模型参数。

**输入**：参数集名称（A/B/C/C0/C1/C2/D/D1/BC1/W2D）
**输出**：`ParameterisedModel` 实例（含全部参数 + 模型创建方法）

**原代码实现**：1 个基类 + 10 个参数集，6,345 行

**抽象层级**：

| 层级 | 细胞模型 | 突触模型 | 行数 | 特点 |
|------|---------|---------|------|------|
| A | 积分-发放（IaF） | 事件突触 | 455 | 最简单 |
| B | IaF + 缝隙连接 | 梯度突触 | 277 | |
| BC1 | 混合 B/C | 混合 | 230 | |
| C | HH 通道（K/Ca） | 双指数突触 | 628 | |
| C0 | C 简化（无 fast K） | 同 C | 711 | |
| C1 | C 变体 | 同 C | 319 | |
| C2 | C + 细胞特异参数 | 同 C | 1,956 | 参数最多 |
| D | 多室形态 | 同 C | 602 | |
| D1 | D 变体 | 同 D | 493 | |
| W2D | 实验性 | 实验性 | 230 | |

**重写后预期**：基类代码 ~300 行 + 10 个 YAML 参数文件 + 加载器 ~200 行，总计 ~500 行代码 + 数据文件

**关键类层次**：

```
BioParameter                    — 单个参数（name/value/source/certainty）
  ↓
ParameterisedModelPrototype     — 参数集合管理（add/get/set）
  ↓
c302ModelPrototype              — 模型创建接口（create_neuron_to_neuron_syn 等）
  ↓
ParameterisedModel（具体类）     — 各层级参数定义 + 模型实现
```

### 功能域 3：网络生成引擎

**职责**：将连接组数据 + 参数化模型组装为 NeuroML 2 网络文档。

**输入**：`(cells, connections, params, config_options)`
**输出**：`neuroml.NeuroMLDocument` 对象

**原代码实现**：`__init__.py::generate()`，1159 行，13 个步骤

**生成步骤提炼**：

```
Step 1:  参数覆盖处理
         ├─ 正则匹配参数覆盖
         └─ 精确匹配参数覆盖
Step 2:  模型组件创建
         ├─ params.create_models()         → 细胞类型定义
         ├─ params.create_neuron_to_neuron_syn() → 神经元突触类型
         └─ params.create_neuron_to_muscle_syn() → 肌肉突触类型
Step 3:  电压范围默认值设置
Step 4:  NeuroML 文档初始化
         └─ neuroml.NeuroMLDocument()
Step 5:  读取连接组数据
         ├─ get_cell_names_and_connection()  → cells, conns
         └─ get_cell_muscle_names_and_connection() → muscles, muscle_conns
Step 6:  创建神经元种群
         ├─ neuroml.Population() / neuroml.Instance()
         └─ 按细胞名称过滤
Step 7:  加载形态 & 分配 3D 位置
         ├─ 从 .cell.nml 文件读取形态
         └─ get_cell_position() / get_muscle_position()
Step 8:  添加偏置电流刺激
         └─ params.get_bioparameter("unitary_bias_*")
Step 9:  创建神经元间突触连接
         ├─ 化学突触 Projection
         └─ 电突触 ElectricalProjection
Step 10: 处理连接覆盖
         ├─ 数量覆盖
         ├─ 极性覆盖
         └─ 缩放覆盖
Step 11: 创建肌肉种群（可选）
Step 12: 创建神经元-肌肉连接
Step 13: 写出 .net.nml 和 LEMS 文件
```

**重写后预期**：拆为 `generator.py`（主流程 ~400 行）、`population.py`（种群创建 ~150 行）、`connection.py`（连接创建 ~200 行）、`stimulation.py`（刺激 ~100 行），总计 ~850 行

### 功能域 4：文件 I/O

**职责**：写出 NeuroML 2 网络文件（`.net.nml`）和 LEMS 仿真文件（`LEMS_*.xml`）。

**输入**：`neuroml.NeuroMLDocument` + 配置参数
**输出**：`.net.nml` 文件 + `LEMS_*.xml` 文件

**原代码实现**：
- `write_to_file()` — 55 行，调用 `pyNeuroML` 写出 NML，用 `airspeed` 模板引擎生成 LEMS
- `merge_with_template()` — 12 行，Velocity 模板合并

**重写后预期**：~100 行，独立 `io.py` 模块

---

### 功能域 5：仿真编排

**职责**：串联 配置加载 → 网络生成 → jNeuroML 仿真 → 结果绘图。

**输入**：配置名称 + 参数集名称 + 运行选项
**输出**：仿真结果文件 + 可视化图表

**原代码实现**：`runAndPlot.py`（621 行）
- `run_c302()` — 核心编排函数
- `__main__` — 200 行 elif 链（硬编码配置×参数组合）

**重写后预期**：~300 行，使用注册表替代 elif 链

---

### 功能域 6：配置脚本

**职责**：定义特定神经网络实验配置（选择哪些细胞、哪些刺激、哪些肌肉）。

**输入**：参数集名称
**输出**：`(cells, cells_to_stimulate, params, muscles_to_include, nml_doc)`

**原代码实现**：16 个 `c302_*.py`，2,983 行

**统一模式**：

```python
def setup(parameter_set, generate=False, ...):
    # 1. 动态加载参数集
    # 2. 定义细胞列表
    # 3. 定义刺激列表
    # 4. 可选：调用 generate()
    # 5. 可选：后处理（额外刺激、连接修改）
    return cells, cells_to_stimulate, params, muscles_to_include, nml_doc
```

**重写后预期**：16 个配置文件统一为声明式结构 + 可选 Python 后处理钩子，约 1,500-2,000 行

## 功能域依赖关系

```
                    ┌───────────────┐
                    │ CLI / 仿真编排 │ ← 功能域 5
                    └───────┬───────┘
                            │
                    ┌───────▼───────┐
                    │  配置脚本      │ ← 功能域 6
                    └───────┬───────┘
                            │
              ┌─────────────▼─────────────┐
              │ 网络生成引擎 + 文件 I/O     │ ← 功能域 3, 4
              │ （含刺激注入子模块）         │
              └─────┬─────────────┬───────┘
                    │             │
              ┌─────▼─────┐ ┌────▼────────┐
              │参数化系统   │ │连接组数据读取│ ← 功能域 2, 1
              └───────────┘ └─────────────┘
```

**重写顺序建议**（自底向上）：
1. 连接组数据读取（功能域 1）— 无内部依赖
2. 参数化系统（功能域 2）— 无内部依赖
3. 文件 I/O（功能域 4）— 依赖 pyNeuroML
4. 网络生成引擎（功能域 3）— 依赖 1、2、4
5. 配置脚本（功能域 6）— 依赖 3
6. CLI / 仿真编排（功能域 5）— 依赖全部
