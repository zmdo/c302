## 包结构设计原则

### 1. 分层对应

| 逻辑层 | 物理包 | 职责边界 |
|--------|--------|----------|
| 数据读取层 | `c302/readers/` | 仅负责读取和解析外部数据，不创建 NeuroML 对象 |
| 参数化层 | `c302/parameters/` | 仅负责参数定义和管理，不直接操作 NeuroML |
| 生成引擎层 | `c302/generator/` | 核心 NeuroML 文档构建，依赖读取层和参数层 |
| 配置层 | `c302/configs/` | 定义实验配置（细胞选择、刺激方案），调用生成引擎 |
| 仿真层 | `c302/simulation/` | 串联生成 → 仿真 → 可视化 |
| 可视化层 | `c302/visualization/` | 仅负责绘图，不做数据处理 |

### 2. 依赖规则

```
readers ← 无内部依赖（仅依赖外部库 cect/xlrd）
parameters ← 无内部依赖（仅依赖 YAML 数据文件）
generator ← readers, parameters
configs ← generator
simulation ← configs, visualization
visualization ← 无内部依赖（仅依赖 matplotlib）
cli ← simulation
```

**禁止**：
- 下层依赖上层（如 readers 不可导入 generator）
- 同层循环依赖（如 configs 内模块互相导入）

### 3. 公共 API 表面

`c302/__init__.py` 仅导出用户直接使用的接口：

```python
# c302/__init__.py
from c302.__version__ import __version__
from c302.generator import generate
from c302.generator.stimulation import add_new_input, add_new_sinusoidal_input
from c302.simulation.runner import run_c302
from c302.cli import main
```

```python
import yaml
from pathlib import Path

def load_parameters(level: str) -> list[BioParameter]:
    """从 YAML 文件加载参数集。

    :param level: 参数层级名称（如 "A", "C2"）
    :return: BioParameter 列表
    """
    yaml_path = _get_data_path() / "parameters" / f"level_{level.lower()}.yaml"
    with open(yaml_path) as f:
        data = yaml.safe_load(f)
    return [BioParameter(**item) for item in data["parameters"]]
```

    """配置注册装饰器。"""
    def decorator(func):
        _CONFIG_REGISTRY[name] = func
        return func
    return decorator

def get_config(name: str) -> callable:

    return list(_CONFIG_REGISTRY.keys())

## 数据路径管理

所有数据文件通过统一路径管理器访问，避免硬编码：

```python
# c302/utils/helpers.py
from pathlib import Path

def get_project_root() -> Path:
    """获取项目根目录（包含 pyproject.toml 的目录）。"""
    current = Path(__file__).resolve().parent
    while current != current.parent:
        if (current / "pyproject.toml").exists():
            return current
        current = current.parent
    raise FileNotFoundError("无法找到项目根目录")

def get_data_dir() -> Path:
    """获取数据目录路径。"""
    return get_project_root() / "data"

def get_morphology_dir() -> Path:
    """获取细胞形态文件目录。"""
    return get_data_dir() / "morphology"

def get_xml_dir() -> Path:
    """获取 XML 资源目录。"""
    return get_data_dir() / "xml"
```
