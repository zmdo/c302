## 等价性验证方案

### 原则

新代码 `project_r1/c302/` 对于相同输入，应产生**语义等价**的 NeuroML 输出。

"语义等价"定义：NeuroML XML 解析后，关键属性一致。不要求：
- XML 标签顺序完全一致
- 注释/空白一致
- ID 命名完全一致（允许命名规范变化）

### 验证指标

| 指标 | 验证方法 |
|------|---------|
| 种群数量 | `len(nml_doc.networks[0].populations)` 一致 |
| 种群中实例数 | 每个种群的实例数一致 |
| 连接总数 | 化学突触 + 电突触连接数一致 |
| 连接权重 | 连接的 `weight` 值一致 |
| 刺激数量 | `PulseGenerator` / `SineGenerator` 数量一致 |
| 刺激参数 | 每个刺激的幅度/延迟/持续时间一致 |
| 参数值 | `BioParameter` 名称-值对完全一致 |
| NeuroML 合规性 | `pynml.validate_neuroml2()` 通过 |

### 验证脚本设计

```python
# tests/test_equivalence.py
"""等价性验证测试。

对每个 (配置, 参数集) 组合：
1. 用原代码生成 .net.nml
2. 用新代码生成 .net.nml
3. 对比两者的语义关键属性
"""
import pytest
from pyneuroml import pynml

CONFIGS = ["IClamp", "Syns", "Full", "FW", "Pharyngeal",
           "Social", "Oscillator", "Muscles"]
PARAM_SETS = ["A", "B", "C"]

@pytest.fixture(scope="session")
def reference_outputs():
    """使用原代码预生成参考输出（一次性）。"""
    ...

@pytest.mark.parametrize("config,params", [
    (c, p) for c in CONFIGS for p in PARAM_SETS
])
def test_network_equivalence(config, params, reference_outputs):
    """验证新生成网络与参考网络语义等价。"""
    ref_doc = reference_outputs[(config, params)]
    new_doc = generate_with_new_code(config, params)

    # 比较种群
    assert len(new_doc.populations) == len(ref_doc.populations)

    # 比较连接
    assert count_connections(new_doc) == count_connections(ref_doc)

    # 比较刺激
    assert count_stimuli(new_doc) == count_stimuli(ref_doc)

    # 比较参数值
    assert compare_bioparameters(new_doc, ref_doc)
```

```yaml

name: Tests

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ["3.10", "3.11", "3.12"]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}
```
