## 核心发现

### 原代码问题统计

| 严重度 | 问题数 | 说明 |
|--------|--------|------|
| 🔴 高 | 4 | 巨型模块、无子包结构、无单元测试、数据与代码混放 |
| 🟡 中 | 7 | 代码重复(~475行,2处)、缺乏 ABC、遗留 Python 2 语法、参数硬编码膨胀(2处)、依赖声明不全 |
| 🟢 低 | 4 | 命名不一致、打包格式老旧、工具函数职责不清、CLI 耦合 |

### 重写核心原则

1. **功能等价**：重写后的代码必须能生成与原代码相同的 NeuroML 2 输出文件
2. **数据外置**：所有参数定义、神经元常量、连接组数据使用数据文件（YAML/JSON），不硬编码在 Python 中
3. **分层清晰**：物理包结构严格对应逻辑架构层
4. **可测试**：每个模块可独立测试，不依赖完整仿真流程
5. **规范先行**：所有代码从第一行起遵循 SP-CODE-2026-001
