## 1. analyse.py 使用 Python 2 语法

**严重度**：🟡 中
**涉及文件**：`analyse.py`（43 行）

### 问题描述

```python
if not volts.has_key(i):    # Python 2 语法，Python 3 抛出 AttributeError
    volts[i] = []
```

`dict.has_key()` 在 Python 3 中已被移除。此脚本在 Python 3 下运行会直接崩溃。

另外，该脚本是纯脚本结构（无函数定义），且功能与 `c302_utils.py` 的 `generate_traces_plot()` 重叠。

### 风险 / 为什么当前能正常工作

该脚本目前可能无人使用（因为 `c302_utils.py` 提供了更好的替代），所以崩溃未被发现。

### 建议修复

1. 修复语法：`if i not in volts:`
2. 封装为函数：`def plot_traces(dat_file):`
3. 移入 `c302/visualization/analyse.py` 或考虑删除（功能重复）

## 3. gen_graph.py 外部依赖未封装

**严重度**：🟢 低
**涉及文件**：`gen_graph.py`（299 行）

### 问题描述

通过 `subprocess` 直接调用 Graphviz CLI（`dot`、`neato`），未做可用性检查：

```python
os.system("dot -Tpng %s -o %s" % (dot_file, png_file))
```

如果系统未安装 Graphviz，仅返回非零退出码，无友好错误提示。

另外，使用 `os.system()` 而非 `subprocess.run()` 是过时的做法。

### 风险 / 为什么当前能正常工作

Graphviz 是科学计算环境中的常见工具，大部分用户已安装。但初次安装时可能遇到不明错误。

### 建议修复

1. 添加 Graphviz 可用性检查（`shutil.which("dot")`）
2. 失败时输出友好提示信息
3. `os.system()` 替换为 `subprocess.run()`

## 5. runAndPlot.py 的 `__main__` 块

**严重度**：🟢 低
**涉及文件**：`runAndPlot.py`（621 行）

### 问题描述

`__main__` 块（约 200 行）硬编码了大量快捷参数组合：

```python
if "-fullC1" in sys.argv:
    run_c302("Full", "C1", ...)
elif "-oscB" in sys.argv:
    run_c302("Oscillator", "B", ...)
# ... 约 40 个 elif 分支
```

这些组合是配置×参数集的笛卡尔积子集，维护成本高。

### 建议修复

将 `__main__` 逻辑提取到 `c302/cli.py` 中，使用 `argparse` 子命令或配置字典替代 elif 链。但优先级低——功能正常，仅影响可维护性。
