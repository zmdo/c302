## 1. 无单元测试框架

**严重度**：🔴 高
**涉及文件**：`test.sh`

### 问题描述

项目唯一的测试入口是 `test.sh`，内容为一系列 `python` 命令行调用，执行的是集成测试（完整仿真流程）。无 pytest / unittest 结构。

缺失项：
- 无 `tests/` 目录
- 无 `conftest.py`
- 无 pytest 配置（`pytest.ini` / `pyproject.toml [tool.pytest]`）
- 无单元测试覆盖核心函数
- 无 CI 中的测试覆盖率统计

### 风险 / 为什么当前能正常工作

集成测试通过 `test.sh` 运行完整仿真，能发现严重的功能回归。但无法：
- 快速定位回归来源（集成测试失败 → 需要 debug 整个流程）
- 验证单个函数的边界条件
- 在不运行 jNeuroML（Java）的情况下执行测试

### 建议修复

```
project/
├── tests/
│   ├── conftest.py           # 共享 fixtures
│   ├── test_core/
│   │   ├── test_generator.py # generate() 子步骤测试
│   │   ├── test_stimulation.py
│   │   ├── test_io.py
│   │   ├── test_positions.py
│   │   └── test_utils.py
│   ├── test_readers/
│   │   ├── test_csv_reader.py
│   │   ├── test_spreadsheet.py
│   │   ├── test_openworm.py
│   │   └── test_white.py
│   ├── test_parameters/
│   │   └── test_bioparameters.py
│   └── test_configs/
│       └── test_config_setup.py
├── pytest.ini                # 或在 pyproject.toml 中配置
```

## 2. 依赖声明不完整

**严重度**：🟡 中
**涉及文件**：`setup.py`

### 问题描述

| 依赖 | 实际使用 | setup.py 声明 |
|------|---------|---------------|
| `matplotlib` | `c302_utils.py`、`analyse.py` 等 | ❌ 未声明 |
| `airspeed` | `__init__.py::merge_with_template()` | ❌ 未声明 |
| `lxml` | `__init__.py`、`gen_graph.py` | ❌ 未声明 |
| `xlwt` | **未使用** | ✅ 声明了（多余） |

`pip install c302` 后，运行时可能因缺少 `matplotlib`/`airspeed`/`lxml` 而崩溃。

### 建议修复

```python
install_requires=[
    "numpy",
    "xlrd",
    "matplotlib",       # 新增
    "airspeed",         # 新增
    "lxml",             # 新增
    "pyNeuroML>=1.3.15",
    "WormNeuroAtlas",
    "cect>=0.3.1",
]
```

移除 `xlwt`。

## 3. 资源文件与源码混放

**严重度**：🟢 低
**涉及文件**：`c302/*.xml`、`c302/*.xls(x)`

### 问题描述

7 个 XML 文件和 2 个电子表格文件与 47 个 .py 文件混放在同一目录：

```
c302/
├── __init__.py          # Python
├── cell_B.xml           # XML 资源
├── cell_C.xml           # XML 资源
├── CElegansNeuronTables.xls  # 数据文件
├── ConnectomeReader.py  # Python
├── custom_synapses.xml  # XML 资源
└── ...
```

### 建议修复

创建 `c302/resources/` 子目录，移入 XML 文件。同时更新 `setup.py` 的 `package_data` 和代码中引用这些文件的路径。

注意：`data/` 和 `NeuroML2/` 已有子目录，做法正确。只需将根目录的 XML/XLS 也归类。

## 4. setup.py 未迁移到 pyproject.toml

**严重度**：🟢 低
**涉及文件**：`setup.py`

### 问题描述

项目仍使用 `setup.py` + `setup()` 调用的传统打包方式。PEP 517/518 推荐使用 `pyproject.toml`。

### 建议修复

在重构包结构后，同步迁移到 `pyproject.toml`：

```toml
[build-system]
requires = ["setuptools>=61.0"]
build-backend = "setuptools.backends._legacy:_Backend"

[project]
name = "c302"
dynamic = ["version"]
dependencies = [...]

[tool.setuptools.packages.find]
where = ["."]
```

## 5. packages 声明硬编码

**严重度**：🟡 中（重构后为 🔴）
**涉及文件**：`setup.py`

### 问题描述

```python
packages=["c302"]  # 硬编码单一包
```

引入子包（`c302.core`、`c302.readers` 等）后，必须改为自动发现：

```python
from setuptools import find_packages
packages=find_packages()
```

否则子包不会被安装。

### 建议修复

在重构包结构的同时更新 `setup.py`（或 `pyproject.toml`）。
